* About
:PROPERTIES:
:CUSTOM_ID: about
:END:

This is a /literate/ Emacs configuration: prose and source code live
together in this file, and Org Babel /tangles/ each ~src~ block out
into the corresponding ~.el~ file under [[file:lisp/][lisp/]].

The intent is a clean separation of concerns:

- *This document* holds the explanation: what each module is for, why
  the non-default knobs are turned, where to find more, install
  recipes, key bindings.
- *The tangled ~.el~ files* hold only the code -- short comments where
  the WHY is non-obvious, function docstrings where Emacs uses them,
  and nothing else.

** Workflow
:PROPERTIES:
:CUSTOM_ID: workflow
:END:

Editing this file and saving it triggers an ~after-save-hook~ that
re-tangles every ~src~ block into its target ~.el~ file.  Editing a
~.el~ directly is supported but the prose here will then drift out of
date -- prefer making non-trivial changes through the org file.

** First run on a new machine
:PROPERTIES:
:CUSTOM_ID: first-run
:END:

~git clone~ + ~emacs~.  The bootstrap in ~init.el~ adds ~lisp/~ to
~load-path~, configures three package archives (GNU ELPA, NonGNU ELPA,
MELPA), and ~require~'s each module in turn.  Missing third-party
packages are downloaded by ~use-package~ on first start; language
servers, the vterm C module, and a handful of optional CLI tools are
installed manually -- see [[#prog][Programming language support]] and
[[#terminal][Terminal]].

* early-init.el                                                   :EARLY:
:PROPERTIES:
:CUSTOM_ID: early-init
:END:

[[file:early-init.el][~early-init.el~]] runs /before/ ~package.el~ is initialised and /before/
any frame is painted.  It is intentionally minimal: only those things
that have to happen *that* early go here.

- *GC tuning during boot.*  The default ~gc-cons-threshold~ (≈800 KiB)
  causes the collector to fire dozens of times while loading Lisp.  We
  raise the threshold to ~most-positive-fixnum~ (effectively "do not
  GC during init") and bump ~gc-cons-percentage~; an
  ~emacs-startup-hook~ resets both to sane runtime values.  At runtime
  ~gcmh-mode~ (loaded from [[#memory][Memory and GC]]) takes over to keep the
  threshold high while busy and low when idle.

- *Disable file-name handlers during init.*  Every ~load~ walks
  ~file-name-handler-alist~ looking for a handler that matches the
  path (TRAMP, jka-compr, archive-mode, ...).  We empty the alist for
  the duration of the boot and restore it afterwards.

- *Hide chrome before the first paint.*  Toolbar, menubar and
  scrollbar are turned off here so the user never sees them flash on
  screen.  Skip the splash and the chatty ~*scratch*~ header for the
  same reason.

- *Take ownership of package activation.*
  ~package-enable-at-startup~ defaults to ~t~, meaning Emacs activates
  every installed package between early-init.el and init.el.  We turn
  it off so ~init.el~ can call ~package-initialize~ at the exact point
  it wants -- after archive priorities and other knobs are set.

- *Quiet native compilation warnings.*  Useful when debugging an elisp
  package, noisy for end users; warnings still go to ~*Warnings*~,
  they just no longer steal focus.

This file is /not/ tangled from the org document -- ~early-init.el~
must exist on disk before Org has had a chance to load.

* Init bootstrap
:PROPERTIES:
:CUSTOM_ID: init
:END:

[[file:init.el][~init.el~]] is the bootstrap entry point and stays small.  Its
responsibilities, in order:

1. *Refuse to start on Emacs < 29.1.*  This config relies on
   ~use-package~, ~eglot~, ~flymake~, tree-sitter and ~which-key~ all
   being built in.  Failing fast with a clear message is friendlier
   than letting the user debug obscure errors later.

2. *Set up ~load-path~ and ~custom-file~.*  ~lisp/~ is prepended to
   ~load-path~; the custom file is redirected to ~custom.el~ (kept
   out of the repo via ~.gitignore~) so interactive ~customize-*~
   never edits ~init.el~.

3. *Configure package archives.*  We pull from GNU ELPA, NonGNU ELPA
   and MELPA, with descending priorities -- GNU first, MELPA last --
   to avoid surprise breakages from MELPA's "always-latest" policy
   when the same package is also in a stable archive.

4. *Disable the Emacs 30 ~compat~ stub.*  Emacs 30 ships a placeholder
   ~lisp/emacs-lisp/compat.el~ that registers the package as built-in
   to stop legacy ~(require 'compat)~ failing.  The stub does not
   contain recent additions like ~static-when~ that modern transient
   (≥ 0.13) and magit (≥ 4.5) need.  We unregister it from
   ~package--builtins~ / ~package--builtin-versions~ so
   ~package-install~ fetches the real GNU ELPA ~compat~.  Symptoms of
   not having this fix: ~void-function static-when~ at runtime, or
   ~transient--init-suffix-key is already defined as something else
   than a generic function~ during byte-compilation.

5. *Refresh archive metadata when stale.*  MELPA / NonGNU prune old
   tarballs as new versions ship.  A metadata snapshot taken weeks
   ago can point to versions that no longer exist on the server,
   producing the classic ~Not found~ error.  We detect a stale local
   cache (older than ~emacs.d/package-refresh-stale-days~, default 7)
   and refresh transparently.

6. *Initialise ~use-package~* with sensible defaults.

7. *Re-tangle ~config.org~ on demand.*  If the org file is newer than
   any module under ~lisp/~ we tangle it before requiring the
   modules.  Together with the editor-side ~after-save-hook~, this
   means edits to ~config.org~ are always reflected in the loaded
   modules without manual intervention.

8. *Require modules in dependency order.*  Memory first (gcmh tunes
   the GC during the rest of the load), UI second (theme + font
   should be in place while later modules report messages), then
   editor, completion, programming, magit, tramp, terminal, sessions,
   tunnels.

This file is /not/ tangled either -- it is the bootstrap.

* Memory and GC                                                  :MEMORY:
:PROPERTIES:
:CUSTOM_ID: memory
:END:

Three layers cooperate to keep Emacs responsive without holding more
RAM than necessary:

1. [[https://gitlab.com/koral/gcmh][gcmh]] raises the GC threshold while you are typing or scrolling
   and lowers it during idle time -- the inverse of the default
   behaviour, which tends to fire the GC right when you press a key.

2. ~read-process-output-max~ is bumped to 1 MiB so LSP servers can
   deliver hundreds of KiB of JSON in a single read instead of many
   small ones (each of which would trigger redisplay).
   ~process-adaptive-read-buffering~ is disabled for the same reason
   -- LSP wants data fast, not "smooth".

3. ~history-*~, ~kill-ring-max~, ~undo-*~ and
   ~large-file-warning-threshold~ are raised to numbers that match
   what modern hardware can comfortably hold.  Notably ~undo-limit~
   defaults silently truncate the history of files larger than ~150
   KiB; bumping the limits costs a handful of MiB and prevents an
   unpleasant surprise on long editing sessions.

#+begin_src emacs-lisp :tangle lisp/setup-memory.el
;;; setup-memory.el --- GC and memory tuning -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Memory and GC".

;;; Code:

(use-package gcmh
  :diminish gcmh-mode
  :init
  (setq gcmh-idle-delay              'auto
        gcmh-auto-idle-delay-factor  10
        gcmh-high-cons-threshold     (* 16 1024 1024))
  :hook (emacs-startup . gcmh-mode))

(setq read-process-output-max         (* 1024 1024)
      process-adaptive-read-buffering nil)

(setq history-length            1000
      history-delete-duplicates t
      kill-ring-max             300
      mark-ring-max             50
      global-mark-ring-max      50)

(setq undo-limit          (* 4  1024 1024)
      undo-strong-limit   (* 6  1024 1024)
      undo-outer-limit    (* 64 1024 1024))

(setq large-file-warning-threshold (* 100 1024 1024))

(provide 'setup-memory)
;;; setup-memory.el ends here
#+end_src

* Look and feel                                                      :UI:
:PROPERTIES:
:CUSTOM_ID: ui
:END:

Visual choices: a dark, low-saturation theme; a font cascade that
falls back gracefully on machines without the preferred face; smooth
modern scrolling; line numbers and current-line highlight in
~prog-mode~ only.

** Theme
:PROPERTIES:
:CUSTOM_ID: theme
:END:

[[https://github.com/rexim/gruber-darker-theme][gruber-darker]] is the choice -- muted, easy on the eyes for long
sessions.

Emacs 30 tightened ~set-face-attribute~ validation: passing ~nil~ as
the value for ~:background~ / ~:foreground~ / ~:underline~ /
~:overline~ now triggers a warning.  Older themes (gruber-darker
included) still pass ~nil~ to mean "no override"; the modern way to
spell that is the symbol ~unspecified~.  An ~:around~ advice on
~set-face-attribute~ rewrites those four colour-like attributes from
~nil~ to ~unspecified~, silencing the warnings without changing the
theme's intent.

** Font cascade
:PROPERTIES:
:CUSTOM_ID: font
:END:

~emacs.d/font-candidates~ is a customisable, ranked list of font
names; the first one actually installed on the machine wins.  Default
ranking starts with /Comic Code Ligatures/ and falls back through
Iosevka, JetBrains Mono, Fira Code, Cascadia Code, DejaVu Sans Mono,
so the same configuration boots cleanly anywhere.  Height is
controlled by ~emacs.d/font-height~ (units are 1/10 of a point, so
220 = 22pt).

** Scrolling and parens
:PROPERTIES:
:CUSTOM_ID: scrolling
:END:

Default scrolling recenters the point when it falls off-screen --
jarring, and unlike any other modern editor.  We set
~scroll-conservatively~, a 3-line top/bottom margin, preserve screen
position, and turn on pixel-precise trackpad scrolling on Emacs 29+.
Matching parens are highlighted with zero delay.

The frame title shows the path of the visited file (or the buffer
name for non-file buffers) so alt-tabbing between Emacs frames works
intuitively.

#+begin_src emacs-lisp :tangle lisp/setup-ui.el
;;; setup-ui.el --- Theme, font, scrolling, line numbers -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Look and feel".

;;; Code:

(require 'cl-lib)

(defun emacs.d/face-attribute-rewrite-nil (orig-fn face frame &rest props)
  "Translate nil to `unspecified' for colour-like face attributes.

Older themes still pass nil to mean \"no override\"; Emacs 30 emits a
warning in that case.  Used as `:around' advice on
`set-face-attribute'."
  (let ((rewritten
         (cl-loop for (k v) on props by #'cddr
                  append (list k
                               (if (and (memq k '(:background :foreground
                                                  :underline  :overline))
                                        (null v))
                                   'unspecified
                                 v)))))
    (apply orig-fn face frame rewritten)))

(advice-add 'set-face-attribute :around
            #'emacs.d/face-attribute-rewrite-nil)

(use-package gruber-darker-theme
  :config (load-theme 'gruber-darker :no-confirm))

(defcustom emacs.d/font-candidates
  '("Comic Code Ligatures"
    "Comic Code"
    "Iosevka"
    "JetBrains Mono"
    "Fira Code"
    "Cascadia Code"
    "DejaVu Sans Mono")
  "Ranked list of fixed-pitch fonts to try, first installed wins."
  :type '(repeat string)
  :group 'emacs.d)

(defcustom emacs.d/font-height 220
  "Height (1/10 of a point) for the default face."
  :type 'integer :group 'emacs.d)

(defun emacs.d/first-installed-font (candidates)
  "Return the first font in CANDIDATES that is installed, or nil."
  (seq-find (lambda (f) (find-font (font-spec :name f))) candidates))

(when-let ((font (emacs.d/first-installed-font emacs.d/font-candidates)))
  (set-face-attribute 'default nil :font font :height emacs.d/font-height))

(add-hook 'prog-mode-hook #'display-line-numbers-mode)
(add-hook 'prog-mode-hook #'hl-line-mode)
(setq display-line-numbers-width-start t)
(column-number-mode 1)
(line-number-mode   1)

(setq scroll-conservatively           101
      scroll-margin                   3
      scroll-preserve-screen-position t
      auto-window-vscroll             nil)

(when (fboundp 'pixel-scroll-precision-mode)
  (pixel-scroll-precision-mode 1))

(setq show-paren-delay 0)
(show-paren-mode 1)

(set-fringe-mode 8)

(setq frame-title-format
      '((:eval (if (buffer-file-name)
                   (abbreviate-file-name (buffer-file-name))
                 "%b"))
        " — Emacs"))

(provide 'setup-ui)
;;; setup-ui.el ends here
#+end_src

* Editor basics                                                  :EDITOR:
:PROPERTIES:
:CUSTOM_ID: editor
:END:

Defaults that turn Emacs from a 1990s text editor into a comfortable
modern one.

- *Short answers* (~y~/~n~ instead of ~yes~/~no~) via the first-class
  ~use-short-answers~ option (Emacs 28+).

- *UTF-8 everywhere* (charset priority, default coding system,
  terminal and keyboard).

- *Spaces by default*, but ~tab-width~ stays at 4 so tab-indented
  files render correctly.  Per-language major modes that legitimately
  want tabs (Makefile, Go) override the default locally.

- *Backup and auto-save under ~var/~.*  By default Emacs litters the
  whole filesystem with ~foo~~ and ~#foo#~ files; we funnel both into
  ~var/backups/~ and ~var/auto-save/~ so the rest of the disk stays
  clean.  Lock files (~.#foo~) are disabled outright -- they confuse
  external tools (webpack, vim, file watchers) and are useful only in
  multi-user setups.

  *Security caveat:* both ~var/auto-save/~ (in-progress edit
  snapshots) and ~var/backups/~ (pre-save copies of every file you
  touch) hold *cleartext* copies of buffer content, including any
  file you opened that contained secrets.  They live under your
  home directory so the OS file permissions are the only barrier.
  No automatic expiry: prune periodically with
  =rm -rf ~/.emacs.d/var/auto-save/* ~/.emacs.d/var/backups/*=.
  =auto-save-visited-mode= -- the more aggressive variant that
  rewrites the visited file in place -- is intentionally /not/
  enabled, and TRAMP buffers also have ~remote-file-name-inhibit-auto-save-visited~
  set so it could not silently push to a remote share even if it
  were turned on.

- *Persistent state.*  Built-in but off by default: ~recentf~ (recent
  files list), ~saveplace~ (point position across sessions),
  ~savehist~ (minibuffer history, search rings, kill ring).

- *Quiet auto-revert*: refresh buffers when the underlying file
  changes, including dired and magit buffers.  Useful when pulling
  git changes from another window.

- *Pairing and selection.*  ~electric-pair-mode~,
  ~delete-selection-mode~ and ~transient-mark-mode~ all on -- the
  expected behaviour in any modern editor.

- *Trailing whitespace.*  Stripped on save, but only in ~prog-mode~
  buffers; in prose (org, markdown) trailing spaces sometimes have
  semantic meaning.

- *Pulse on jump.*  When you switch window or use ~windmove~, the
  destination line briefly pulses so the eye can follow.

- *Auto-tangle of ~config.org~.*  Saving the org file regenerates the
  affected ~setup-*.el~ in place.

#+begin_src emacs-lisp :tangle lisp/setup-editor.el
;;; setup-editor.el --- Core editing behaviour -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Editor basics".

;;; Code:

(setq use-short-answers t)

(set-charset-priority 'unicode)
(prefer-coding-system        'utf-8-unix)
(set-default-coding-systems  'utf-8-unix)
(set-terminal-coding-system  'utf-8-unix)
(set-keyboard-coding-system  'utf-8-unix)
(setq locale-coding-system   'utf-8-unix)

(setq-default indent-tabs-mode nil
              tab-width        4)

(let ((backup-dir   (expand-file-name "var/backups/"   user-emacs-directory))
      (autosave-dir (expand-file-name "var/auto-save/" user-emacs-directory)))
  (make-directory backup-dir   t)
  (make-directory autosave-dir t)
  (setq backup-directory-alist         `(("." . ,backup-dir))
        auto-save-file-name-transforms `((".*" ,autosave-dir t))
        backup-by-copying              t
        version-control                t
        delete-old-versions            t
        kept-new-versions              5
        kept-old-versions              2))

(setq create-lockfiles      nil
      require-final-newline t
      ring-bell-function    'ignore)

(use-package recentf
  :ensure nil
  :init   (setq recentf-max-saved-items 200
                recentf-max-menu-items  25
                recentf-auto-cleanup    'never)
  :config (recentf-mode 1))

(use-package saveplace
  :ensure nil
  :config (save-place-mode 1))

(use-package savehist
  :ensure nil
  :init   (setq savehist-additional-variables
                '(search-ring regexp-search-ring kill-ring))
  :config (savehist-mode 1))

(use-package autorevert
  :ensure nil
  :init (setq auto-revert-verbose                nil
              global-auto-revert-non-file-buffers t)
  :config (global-auto-revert-mode 1))

(electric-pair-mode    1)
(delete-selection-mode 1)
(transient-mark-mode   1)

(defun emacs.d/strip-trailing-whitespace-prog ()
  "Strip trailing whitespace in `prog-mode' buffers only."
  (when (derived-mode-p 'prog-mode)
    (delete-trailing-whitespace)))

(add-hook 'before-save-hook #'emacs.d/strip-trailing-whitespace-prog)

(add-hook 'text-mode-hook #'visual-line-mode)

(when (fboundp 'pulse-momentary-highlight-one-line)
  (defun emacs.d/pulse-line (&rest _) (pulse-momentary-highlight-one-line (point)))
  (dolist (cmd '(other-window
                 windmove-up windmove-down windmove-left windmove-right))
    (advice-add cmd :after #'emacs.d/pulse-line)))

(defun emacs.d/auto-tangle-config ()
  "Tangle `config.org' on save when the current buffer is that file."
  (when (and buffer-file-name
             (string-equal (file-name-nondirectory buffer-file-name)
                           "config.org")
             (file-equal-p (file-name-directory buffer-file-name)
                           user-emacs-directory))
    (let ((org-confirm-babel-evaluate nil))
      (org-babel-tangle))))

(add-hook 'after-save-hook #'emacs.d/auto-tangle-config)

(provide 'setup-editor)
;;; setup-editor.el ends here
#+end_src

* Completion                                                :COMPLETION:
:PROPERTIES:
:CUSTOM_ID: completion
:END:

The "modern" Emacs completion stack -- small, modular, each package
does one thing and they compose freely.

| Layer             | Package                       | Role                                            |
|-------------------+-------------------------------+-------------------------------------------------|
| Minibuffer UI     | [[https://github.com/minad/vertico][vertico]]                       | Vertical candidate list                         |
| Annotations       | [[https://github.com/minad/marginalia][marginalia]]                    | File size, key, docstring next to candidates    |
| Matching style    | [[https://github.com/oantolin/orderless][orderless]]                     | Type space-separated tokens in any order        |
| Search & navigate | [[https://github.com/minad/consult][consult]]                       | Buffer / line / imenu / ripgrep pickers         |
| In-buffer popup   | [[https://github.com/minad/corfu][corfu]]                         | VSCode-style autocomplete inside a buffer       |
| Extra backends    | [[https://github.com/minad/cape][cape]]                          | File paths, dabbrev, keywords for ~corfu~       |
| Key hints         | ~which-key~ (built in 30+)    | Pop-up listing keys after a prefix              |

A note on ~orderless~: the ~completion-styles~ list also keeps the
built-in ~basic~ style as a fallback, which is necessary for
prefix-driven completion (TRAMP file names in particular) to work.

Consult bindings worth remembering:

| Key       | Command                       |
|-----------+-------------------------------|
| ~C-x b~   | ~consult-buffer~              |
| ~M-y~     | ~consult-yank-pop~            |
| ~M-g g~   | ~consult-goto-line~           |
| ~M-g i~   | ~consult-imenu~               |
| ~M-s l~   | ~consult-line~                |
| ~M-s r~   | ~consult-ripgrep~ (needs =rg=)|
| ~M-s f~   | ~consult-find~                |

;;; setup-completion.el --- Minibuffer + in-buffer completion -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Completion".

;;; Code:

(use-package vertico
  :init (vertico-mode 1)
  :custom
  (vertico-cycle  t)
  (vertico-resize t)
  (vertico-count  14)
  :config
  ;; Candidates grow upward above the input line; the prompt stays
  ;; pinned at the bottom of the minibuffer, in your line of sight.
  (require 'vertico-reverse)
  (vertico-reverse-mode 1))

(use-package marginalia
  :after vertico
  :init (marginalia-mode 1))

(use-package orderless
  :custom
  ;; Fall back to `basic' so prefix-driven completion (TRAMP file
  ;; names, in particular) keeps working.
  (completion-styles '(orderless basic))
  (completion-category-overrides
   '((file (styles basic partial-completion)))))

(use-package consult
  :bind
  (("C-x b"   . consult-buffer)
   ("C-x 4 b" . consult-buffer-other-window)
   ("C-x p b" . consult-project-buffer)
   ("M-y"     . consult-yank-pop)
   ("M-g g"   . consult-goto-line)
   ("M-g i"   . consult-imenu)
   ("M-s l"   . consult-line)
   ("M-s r"   . consult-ripgrep)
   ("M-s f"   . consult-find))
  :custom
  (consult-narrow-key  "<")
  (consult-preview-key 'any))

(use-package corfu
  :init (global-corfu-mode 1)
  :custom
  (corfu-auto              t)
  (corfu-auto-prefix       2)
  (corfu-auto-delay        0.1)
  (corfu-cycle             t)
  (corfu-quit-no-match     'separator)
  (corfu-preselect         'prompt)
  (corfu-echo-documentation 0.25))

(use-package cape
  :init
  (add-to-list 'completion-at-point-functions #'cape-dabbrev)
  (add-to-list 'completion-at-point-functions #'cape-file)
  (add-to-list 'completion-at-point-functions #'cape-keyword))

(use-package which-key
  :ensure nil
  :diminish which-key-mode
  :init (setq which-key-idle-delay 0.5
              which-key-popup-type 'minibuffer)
  :config (which-key-mode 1))

(provide 'setup-completion)
;;; setup-completion.el ends here

** Auto-starting Eglot
:PROPERTIES:
:CUSTOM_ID: prog-eglot-modes
:END:

The variable ~emacs.d/eglot-auto-modes~ lists the major modes for
which Eglot should auto-attach.  Eglot only actually starts when the
matching language server is found on ~PATH~, so leaving entries here
for languages whose server you have not installed is harmless --

** Installing language servers
:PROPERTIES:
:CUSTOM_ID: prog-lsp-install
:END:

Eglot does *not* install language servers (unlike ~lsp-mode~ with
~lsp-install-server~ or ~mason.nvim~ on the Neovim side).  Three
reasonable strategies, in increasing order of reproducibility:

1. *System-wide* via distro packages (quick, requires sudo, version
   pinned by your distro).
2. *Per-user* (recommended): ~pip install --user~,
   ~rustup component add rust-analyzer~, ~go install ...@latest~,
   ~npm i -g ...~ with a user prefix.  No sudo, easy to upgrade,
   isolated from system Python/Node.
3. *Per-project* via ~nix develop~, ~mise~, ~asdf~, a devcontainer or
   a project-local virtualenv.  Most reproducible -- each project
   carries its own pinned version.

* TRAMP                                                          :TRAMP:
:PROPERTIES:
:CUSTOM_ID: tramp
:END:

Open ~/ssh:host:/path~ to edit a remote file as if it were local.

This module trades a bit of TRAMP's default paranoia for a much
faster experience over SSH while keeping the security properties of
plain ~ssh~ -- host-key checking is *never* disabled.

Pre-requisites on the local machine:

- a working ~ssh~ on ~PATH~ (Emacs uses the system OpenSSH);
- an ~~/.ssh/config~ with ~ControlMaster auto~ for the hosts you visit
  often.  With ControlMaster set up every TRAMP operation reuses the
  same SSH connection -- the single biggest speed win for remote
  editing.  Sample block:

  #+begin_example
  Host *
      ControlMaster auto
      ControlPath   ~/.ssh/cm-%r@%h:%p
      ControlPersist 10m
      ServerAliveInterval 60
  #+end_example

Notable knobs we set:

- ~tramp-default-method "ssh"~ -- uses your OpenSSH client and
  benefits from ControlMaster.
- ~tramp-verbose 1~ silences the per-step "Connecting to..."
  progress noise; bump it back to 6 when debugging a connection.
- ~vc-handled-backends '(Git)~ -- TRAMP probes every visited file for
  VCS metadata, slow over SSH.  We restrict it to Git (Magit talks
  through one shared SSH session and is fast on remote repos).
- ~tramp-archive-enabled nil~ -- the archive handler matches archive
  members on remote paths and slows down every find-file.
- ~remote-file-name-inhibit-auto-save-visited t~ -- auto-saving over
  SSH is slow and the local copy defeats the point of editing
  remotely; ~C-x C-s~ still saves explicitly.
- ~recentf~ excludes remote files (they expire / change IPs and probing
  them on startup is slow), and ~saveplace~ skips them too.

#+begin_src emacs-lisp :tangle lisp/setup-tramp.el
;;; setup-tramp.el --- Remote editing over SSH -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "TRAMP".

;;; Code:

(defun emacs.d/save-place-skip-remote (orig-fn &rest args)
  "Around-advice that skips `save-place' bookkeeping for remote files."
  (unless (and buffer-file-name (file-remote-p buffer-file-name))
    (apply orig-fn args)))

(use-package tramp
  :ensure nil
  :defer t
  :custom
  (tramp-default-method                       "ssh")
  (tramp-verbose                              1)
  (tramp-persistency-file-name
   (expand-file-name "var/tramp" user-emacs-directory))
  (vc-handled-backends                        '(Git))
  (tramp-completion-reread-directory-timeout  nil)
  :config

    (add-to-list 'recentf-exclude (lambda (f) (file-remote-p f))))
  (with-eval-after-load 'saveplace
    (advice-add 'save-place-to-alist :around
                #'emacs.d/save-place-skip-remote))
  (setq tramp-archive-enabled                  nil
        remote-file-name-inhibit-auto-save-visited t)
  (add-to-list 'tramp-remote-path 'tramp-own-remote-path))

* Terminal: vterm + tab-bar                                  :TERMINAL:
:PROPERTIES:
:CUSTOM_ID: terminal
:END:

The "Emacs as a daily SSH terminal" stack: each remote session lives
in its own ~tab-bar~ tab and the tab title is /dynamic/ -- it shows
the bastion / jump host the session was opened against, plus the
hostname extracted from the current shell prompt.

** vterm
:PROPERTIES:
:CUSTOM_ID: terminal-vterm
:END:

[[https://github.com/akermu/emacs-libvterm][vterm]] is an NCURSES-compatible terminal that runs full TUIs (htop,
vi, less, tmux, interactive password prompts) without surprises.  We
prefer it over the built-in ~term~/~ansi-term~/~eshell~ for these
workloads because it's the only one that handles complex remote
sessions transparently.

First boot compiles a small C module against ~libvterm~.  The
package tries the system ~libvterm~ first; if ~libvterm-dev~ (Debian)
/ ~libvterm-devel~ (RHEL) headers are missing it falls back to
downloading and building libvterm via cmake's FetchContent.  Either
way ~cmake~, ~gcc~ and ~libtool~ are needed.

Bindings:

| Key         | Where               | Action                          |
|-------------+---------------------+---------------------------------|
| ~C-c v~     | global              | open a *local* vterm            |
| ~C-c C-t~   | inside vterm        | toggle ~vterm-copy-mode~        |
| ~C-c s s~   | global              | open a saved SSH session in a tab (see [[#ssh-sessions][SSH sessions]]) |

A few non-default options:

- ~vterm-max-scrollback 10000~ keeps a useful amount of scrollback
  without blowing memory on long-running sessions.
- ~vterm-kill-buffer-on-exit nil~ keeps the buffer around after the
  process exits so the last lines of output (e.g. SSH error
  messages) remain readable.

** Tab bar
:PROPERTIES:
:CUSTOM_ID: terminal-tab-bar
:END:

|-----------------+------------------------------|

| ~C-<tab>~       | next tab (built-in default)  |
| ~C-S-<tab>~     | previous tab (built-in default) |

** Dynamic tab title
:PROPERTIES:
:CUSTOM_ID: terminal-dynamic-title
:END:

Five buffer-local variables drive the title machinery:

- ~emacs.d/vterm-bastion-name~ -- string set once when the session is
  opened (by [[#ssh-sessions][setup-ssh-sessions]]).  Static for the lifetime of the
  session.  Used as the prefix of the tab title and as the first
  hop of the TRAMP chain.
- ~emacs.d/vterm-current-host~ -- updated by parsing the latest
  visible shell prompt against ~emacs.d/vterm-prompt-host-regexp~.
  May be nil while the prompt is still being drawn.
- ~emacs.d/vterm-current-user~ -- user name captured from the same
  prompt.  Lets the TRAMP path chain an extra ~|sudo:USER~ hop when
  the session has elevated/deescalated on the target via ~sudo su -~.
- ~emacs.d/vterm-current-path~ -- working directory captured from the
  same prompt.  Optional: nil when PS1 does not expose a cwd.
- ~emacs.d/vterm-tab-name~ -- the tab title last installed.  Stored
  so the right tab can be located by name when the host changes,
  even if the user has switched to a different tab in the meantime.

The default regexp is anchored at column zero and captures user
(group 1), host (group 2) and optional cwd (group 3):

#+begin_example
user@host$              # user + host
user@host:~/foo$        # user + host + path
root@host:/etc#         # root shell on host (prompt char `#')
oracle@target:/u01/app$ # after `sudo su - oracle' on a target host
#+end_example

No remote ~.bashrc~ modification is required -- we read what is
already on screen.  PS1 shapes that do not start at column zero
or do not end with one of ~$ # % >~ won't match the default
regexp; customise ~emacs.d/vterm-prompt-host-regexp~ if your
environment uses an unusual prompt.

The strategy is to /not/ intercept ~tab-bar-tab-name-function~ (which
is invoked for every tab on every redraw and forces a 0-arg
signature), and instead explicitly call ~tab-bar-rename-tab~
whenever the session detects a new host.  The relevant tab is
located by name through the helper ~emacs.d/tab-bar-rename-tab-by-name~,
so the rename works regardless of which tab is currently selected.

The buffer name is renamed too -- but with the cwd appended:

#+begin_example
tab    →  bast-prod: lxdoma001                       (stable identity)
buffer → *ssh: bast-prod: lxdoma001 — ~/etc/foo*     (with current cwd)
#+end_example

Rationale: the tab is the session's stable identity (used to
navigate between sessions), so it changes only when the host you're
logged into changes -- a relatively rare event (an extra ~ssh~ hop,
a ~sudo su~ that bumps the prompt).  The cwd, on the other hand,
moves on every ~cd~ and belongs in the place Emacs already reserves
for "where am I now" -- the mode-line / ~C-x b~ list, i.e. the
buffer name.  This keeps the tab bar from jittering horizontally
while you wander around the filesystem.

To prevent vterm from also renaming the buffer when the remote
shell sends an OSC title escape (which would clash with our manual
rename), session vterms set ~vterm-buffer-name-string~ to ~nil~
buffer-locally.  Regular vterms opened with ~C-c v~ keep the
default ~"vterm: %s"~ title-driven name.

** TRAMP path tracking
:PROPERTIES:
:CUSTOM_ID: terminal-tramp
:END:

Once user, host and cwd are extracted from the prompt we have
*enough* to assemble the TRAMP path pointing at exactly the same
remote location -- a strict superset of what the title machinery
needs.  Plain ssh aliases get a single-hop path; bastions that
auto-elevate (CyberArk PSMP with ~RemoteCommand sudo -i~ in their
ssh_config) need a multi-hop chain that mirrors the interactive
sequence: ~ssh~ to the bastion, ~sudo~ into root, optionally
another ~ssh~ to a target, optionally another ~sudo~ into a
different user on the target.

Writing the full chain inline in `default-directory' would *seem*
to be the obvious approach (e.g.
=/ssh:bastion|sudo:root@bastion|ssh:target|sudo:oracle@target:/=)
-- but it triggers a TRAMP bug present at least up to Emacs 30.1:
when the chain ends with a `sudo' hop on a host different from
the previous hop, ~tramp-add-hops~ generates an intermediate
proxy entry with a *nil user-regexp* (matching any user) and
~add-to-list~ puts it before the legitimate target-specific
entry.  TRAMP's hop-walking loop then matches the wrong proxy
first, skipping the intermediate ~ssh:target~ step entirely.
The visible symptom is

#+begin_example
File error: Couldn't find command to check if file exists
, Host name `target' does not match `^bastion$'
#+end_example

To avoid this, we install our own proxy entries in
~tramp-default-proxies-alist~ with anchored user regexes
(`\\`USER\\'' for a named user, `\\`\\'' for the empty user that
intermediate ssh-only hops carry) and set ~default-directory~ to
a *minimal-form* path -- just one or two TRAMP methods, the
remainder is supplied by the proxy table.  Side effect: our
proxies are added to ~tramp-default-proxies-alist~ globally (they
are tiny, mutually-exclusive triples; no cleanup on session
close).

Sudo is *opt-in per host*: by default
~emacs.d/vterm-tramp-sudo-user~ is nil, so a plain
~ssh~ to a personal box yields just ~/ssh:HOST:CWD/~ with no
sudo prompt.  Bastions that need the sudo hop are declared once
in ~emacs.d/ssh-host-tramp-config~ (regexp-keyed alist):

#+begin_src emacs-lisp :tangle no
(setq emacs.d/ssh-host-tramp-config
      '(("\\`\\(lx\\|kx\\)sag" :sudo-user "root")
        ;; ... add more bastion patterns here
        ))
#+end_src

Resulting ~default-directory~ shapes (minimal form -- the rest of
the chain comes from the proxy entries we install per session):

#+begin_example
A. Plain ssh, on bastion:
   default-directory = /ssh:TRAMP-ALIAS:CWD
   proxies           = (none)

B. Plain ssh, hopped to a target:
   default-directory = /ssh:TARGET:CWD
   proxies           = (\`TARGET\' \`\'  /ssh:TRAMP-ALIAS:)

C. With sudo, on bastion:
   default-directory = /sudo:SUDO@TRAMP-ALIAS:CWD
   proxies           = (\`TRAMP-ALIAS\' \`SUDO\' /ssh:TRAMP-ALIAS:)

D. With sudo, on target as SUDO-USER (typically root):
   default-directory = /ssh:TARGET:CWD
   proxies           = (\`TARGET\' \`\'      /sudo:SUDO@TRAMP-ALIAS:)
                       (\`TRAMP-ALIAS\' \`SUDO\' /ssh:TRAMP-ALIAS:)

E. With sudo, on target as USER (after sudo su - oracle):
   default-directory = /sudo:USER@TARGET:CWD
   proxies           = (\`TARGET\' \`USER\'   /ssh:TARGET:)
                       (\`TARGET\' \`\'       /sudo:SUDO@TRAMP-ALIAS:)
                       (\`TRAMP-ALIAS\' \`SUDO\' /ssh:TRAMP-ALIAS:)
#+end_example

The bench under ~~/gitprj/podman/psmp-test/~ reproduces case E
end-to-end against a containerised PSMP-like bastion, and is the
test harness for changes to this layer.

Two modes of using this:

- *Auto-sync (default, ~emacs.d/vterm-tramp-auto-sync = t~)*: every
  time the prompt detects a host / user / cwd change, the vterm
  buffer's ~default-directory~ is updated to the matching TRAMP
  path.  ~C-x C-f~ inside that buffer now starts at the remote
  location, as does dired, ~M-!~, ~compile~, ~magit-status~ and
  every other command that reads ~default-directory~.  Powerful
  but invasive: anything you do *from that buffer* "thinks" it's
  on the remote machine.

- *Manual mode (set ~emacs.d/vterm-tramp-auto-sync~ to nil)*:
  ~default-directory~ is left alone.  Two dedicated commands
  cross to the remote on demand without touching the buffer's
  state:
  - ~C-c f~ -- ~emacs.d/vterm-find-file-remote~ wraps ~find-file~.
  - ~C-c d~ -- ~emacs.d/vterm-dired-remote~ wraps ~dired~.
  Both delegate through the helper ~emacs.d/vterm--cross-to-remote~,
  so adding more "remote-aware" commands is one line each.

The auto-sync code path is conservative: it only runs in *session*
vterms (i.e. those with ~emacs.d/vterm-tab-name~ set), it only
recomputes when host / user / cwd actually change, and it bails
out silently if any of the three are still unknown.

A compact mode-line segment ~ ⇄BASTION[→HOST]~ shows the live SSH
chain when the buffer's ~default-directory~ is a TRAMP path -- so
at a glance you can tell whether the session is connected through
the bastion only (~ ⇄zero~) or has hopped further (~ ⇄zero→target~).
Hovering shows the full TRAMP path as a tooltip.  The segment is
appended to ~mode-line-misc-info~ globally but only renders inside
session vterms; everywhere else its evaluator returns nil.

** Closing sessions
:PROPERTIES:
:CUSTOM_ID: terminal-closing
:END:

Two related conveniences for the SSH workflow:

- *Dismissing a dead session.*  When the remote shell exits (you
  typed ~exit~, SSH dropped, CyberArk PSMP timed you out), the buffer
  is intentionally left around so the last lines of output remain
  readable.  ~vterm-exit-functions~ installs a minimal local keymap
  inheriting from the existing one, with a single addition: ~q~
  bound to ~kill-current-buffer~.  A ~[exited]~ marker is added to
  the mode line so the dead state is visible at a glance.

- *Auto-closing the tab.*  When a session vterm buffer is killed
  (via ~q~ or ~kill-buffer~), the tab that hosted it is closed too
  -- otherwise the user ends up with orphan tabs each pointing at
  ~*scratch*~.  This is opt-in: only vterms opened by [[#ssh-sessions][setup-ssh-sessions]]
  install the ~kill-buffer-hook~; vterms launched casually with
  ~C-c v~ keep the default Emacs "leave the tab open" behaviour.
  The very last tab on the frame is preserved (closing it would
  signal an error and the user almost certainly wants to keep the
  frame).

#+begin_src emacs-lisp :tangle lisp/setup-terminal.el
;;; setup-terminal.el --- vterm + tab-bar -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Terminal: vterm + tab-bar".

;;; Code:

(use-package vterm
  :commands (vterm vterm-other-window)
  :custom
  (vterm-max-scrollback     10000)
  (vterm-kill-buffer-on-exit nil)
  (vterm-buffer-name-string "vterm: %s")
  (vterm-shell (or explicit-shell-file-name (getenv "SHELL") "/bin/bash"))
  :bind

(defcustom emacs.d/vterm-prompt-host-regexp
  (concat "^\\[?"                                ; optional `[' (RHEL/Fedora)
          "\\([[:alnum:]_.-]+\\)"                ; 1: user
          "@"
          "\\([[:alnum:]_.-]+\\)"                ; 2: host
          "\\(?:[: \t]+"                         ; separator: `:' or whitespace
          "\\([^][:space:]\n]+?\\)\\)?"          ; 3: cwd (optional, no `]')
          "\\]?"                                 ; optional closing `]'
          "[ \t]*[$#%>]")                        ; prompt char
  "Regexp used to extract user, host and cwd from the visible shell prompt.
Capture groups in order: USER (group 1), HOST (group 2), CWD
(group 3, optional).  Anchored at column zero.  Handles both the
Debian/Ubuntu shape (`user@host:cwd$') and the RHEL/Fedora
bracketed shape (`[user@host cwd]$').  Customise for prompts that
don't end with `$', `#', `%' or `>' (e.g. starship/powerline arrows)."
  :type 'regexp :group 'emacs.d)

(defcustom emacs.d/vterm-tramp-sudo-user nil
  "Default user TRAMP sudoes into after the ssh hop to the bastion.
Set to a string (e.g. \"root\") only if *every* ssh alias you open
auto-elevates after login; for a mixed environment leave this nil
and use `emacs.d/ssh-host-tramp-config' to opt in per host."
  :type '(choice (const :tag "No sudo by default" nil) string)
  :group 'emacs.d)

(defcustom emacs.d/vterm-tramp-bastion-user "root"
  "Default user the session is expected to be running as after the
bastion sudo.  Compared against the prompt-detected user to decide
whether an *extra* `|sudo:USER' hop is needed (e.g. after `sudo
su - oracle' on the target).  Per-host override via
`emacs.d/ssh-host-tramp-config'."
  :type 'string :group 'emacs.d)

(defcustom emacs.d/ssh-host-tramp-config nil
  "Per-host TRAMP overrides matched against ssh_config aliases.
Alist where each car is a regexp matched (with `string-match-p')
against the alias passed to `emacs.d/ssh-sessions-open', and each
cdr is a plist with these recognised keys:

  :sudo-user STRING    Become this user via sudo right after the
                       ssh hop (e.g. \"root\" for a CyberArk-style
                       bastion that auto-runs `RemoteCommand sudo
                       -i').  nil disables the sudo hop entirely.

  :bastion-user STRING The user the session is expected to be
                       running as after that sudo (default
                       inherited from `emacs.d/vterm-tramp-bastion-user').
                       An *extra* sudo is added if the prompt's
                       user differs (e.g. after `sudo su - oracle').

  :tramp-alias VALUE   Use this ssh_config alias *for the TRAMP
                       path only*, instead of the alias used for
                       the interactive vterm session.  Needed when
                       the interactive entry has `RemoteCommand'
                       or `RequestTTY' settings that confuse
                       TRAMP's prompt detection: keep the original
                       alias for vterm, declare a clean variant
                       (no RemoteCommand, no RequestTTY) and
                       point :tramp-alias at it.  VALUE may be a
                       string (used verbatim) or a function of one
                       argument (the bastion alias) returning a
                       string.

The first matching entry wins; aliases that match no entry use
the global defaults.  Example:

  \\='((\"\\\\`\\\\(lx\\\\|kx\\\\)sag\"
     :sudo-user   \"root\"
     :tramp-alias (lambda (b) (concat b \"-tramp\")))
    (\"\\\\`my-vps\\\\'\" :sudo-user nil))"
  :type '(alist :key-type regexp :value-type plist)
  :group 'emacs.d)

(defcustom emacs.d/vterm-tramp-auto-sync t
  "When non-nil, continuously sync `default-directory' of session vterms
to a TRAMP path matching the prompt-derived remote location.  This
makes `C-x C-f', dired, magit, `compile' and `M-!' from the vterm
buffer all target the remote machine.  Set to nil to leave
`default-directory' alone and cross to the remote only on demand,
through `emacs.d/vterm-find-file-remote' (bound to `C-c f' in
vterm-mode)."
  :type 'boolean :group 'emacs.d)

(defun emacs.d/vterm-extract-prompt-context ()
  "Return (USER HOST PATH) from the most recent prompt, or nil.
Each element may be nil if its capture group did not match.  Scans
back at most 50 lines from `point-max'."
  (save-excursion
    (goto-char (point-max))
    (let ((window-start (max (point-min)
                             (save-excursion (forward-line -50) (point)))))
      (when (re-search-backward emacs.d/vterm-prompt-host-regexp
                                window-start t)
        (list (match-string-no-properties 1)
              (match-string-no-properties 2)
              (and (match-beginning 3) (match-string-no-properties 3)))))))

(defun emacs.d/vterm--tramp-host-config (alias)
  "Return the plist of TRAMP overrides for ALIAS, or nil.
Walks `emacs.d/ssh-host-tramp-config' and returns the cdr of the
first entry whose car (a regexp) matches ALIAS."
  (cdr (cl-find-if (lambda (entry)
                     (string-match-p (car entry) alias))
                   emacs.d/ssh-host-tramp-config)))

(defun emacs.d/vterm--tramp-resolved (alias key default)
  "Look up KEY for ALIAS in `emacs.d/ssh-host-tramp-config'.
Falls back to DEFAULT when ALIAS matches no entry, or when the
matched entry does not include KEY."
  (let ((cfg (emacs.d/vterm--tramp-host-config alias)))
    (if (plist-member cfg key)
        (plist-get cfg key)
      default)))

(defun emacs.d/vterm--tramp-resolve-alias (bastion)
  "Return the ssh_config alias TRAMP should use for BASTION.
Honors a `:tramp-alias' entry in `emacs.d/ssh-host-tramp-config'
(string used verbatim, or function called with BASTION); falls
back to BASTION itself."
  (let ((override (emacs.d/vterm--tramp-resolved bastion :tramp-alias nil)))
    (cond
     ((stringp override)   override)
     ((functionp override) (funcall override bastion))
     (t                    bastion))))

(defun emacs.d/vterm--tramp-anchor (str-or-empty)
  "Wrap STR-OR-EMPTY in `\\`...\\''-anchored regexp form.
Returns `\\`\\''  (the empty-string-only matcher) when STR-OR-EMPTY
is nil or empty -- TRAMP treats this as `user not specified',
preventing the proxy entry from matching arbitrary users."
  (if (or (null str-or-empty) (string-empty-p str-or-empty))
      "\\`\\'"
    (concat "\\`" (regexp-quote str-or-empty) "\\'")))

(defun emacs.d/vterm--tramp-chain (bastion tramp-alias host user path
                                           sudo-user bastion-user)
  "Return `(DEEPEST-PATH . PROXY-ENTRIES)' describing the TRAMP setup
matching the prompt-derived session state.  DEEPEST-PATH is the
minimal-form TRAMP path (single or two-method) that
`default-directory' should hold; PROXY-ENTRIES is a list of
`(HOST-RX USER-RX PROXY-STRING)' triples to add to
`tramp-default-proxies-alist' so TRAMP can resolve DEEPEST-PATH
into the full multi-hop chain.

The shape of the chain is chosen from five cases:

  A. plain ssh, on bastion             /ssh:TRAMP-ALIAS:CWD
  B. plain ssh, hopped to a target     /ssh:HOST:CWD
  C. with sudo, on bastion             /sudo:SUDO-USER@TRAMP-ALIAS:CWD
  D. with sudo, on target as SUDO-USER /ssh:HOST:CWD
  E. with sudo, on target as USER      /sudo:USER@HOST:CWD

This split exists because TRAMP's ad-hoc chain parsing
(`tramp-add-hops') generates proxy entries with a nil user-regexp
that matches *any* user and beats the legitimate intermediate
entries -- producing the `Host name X does not match Y' error
when the chain has more than 3 hops.  By building the proxy list
ourselves with anchored user regexes the ordering bug is avoided."
  (let* ((on-bastion (string-equal host bastion))
         (path/      (file-name-as-directory (or path "~")))
         deepest entries)
    (cond
     ((and (not sudo-user) on-bastion)                     ; A
      (setq deepest (format "/ssh:%s:%s" tramp-alias path/)))
     ((not sudo-user)                                       ; B
      (setq deepest (format "/ssh:%s:%s" host path/))
      (push (list (emacs.d/vterm--tramp-anchor host)
                  "\\`\\'"
                  (format "/ssh:%s:" tramp-alias))
            entries))
     (on-bastion                                            ; C
      (setq deepest (format "/sudo:%s@%s:%s"
                            sudo-user tramp-alias path/))
      (push (list (emacs.d/vterm--tramp-anchor tramp-alias)
                  (emacs.d/vterm--tramp-anchor sudo-user)
                  (format "/ssh:%s:" tramp-alias))
            entries))
     ((string-equal user bastion-user)                      ; D
      (setq deepest (format "/ssh:%s:%s" host path/))
      (push (list (emacs.d/vterm--tramp-anchor host)
                  "\\`\\'"
                  (format "/sudo:%s@%s:" sudo-user tramp-alias))
            entries)
      (push (list (emacs.d/vterm--tramp-anchor tramp-alias)
                  (emacs.d/vterm--tramp-anchor sudo-user)
                  (format "/ssh:%s:" tramp-alias))
            entries))
     (t                                                     ; E
      (setq deepest (format "/sudo:%s@%s:%s" user host path/))
      (push (list (emacs.d/vterm--tramp-anchor host)
                  (emacs.d/vterm--tramp-anchor user)
                  (format "/ssh:%s:" host))
            entries)
      (push (list (emacs.d/vterm--tramp-anchor host)
                  "\\`\\'"
                  (format "/sudo:%s@%s:" sudo-user tramp-alias))
            entries)
      (push (list (emacs.d/vterm--tramp-anchor tramp-alias)
                  (emacs.d/vterm--tramp-anchor sudo-user)
                  (format "/ssh:%s:" tramp-alias))
            entries)))
    (cons deepest entries)))

(defun emacs.d/vterm--tramp-default-directory ()
  "Side-effecting wrapper around `emacs.d/vterm--tramp-chain'.
Returns the deepest TRAMP path matching the current session
prompt, and installs the proxy entries it needs in
`tramp-default-proxies-alist' (idempotently, no removal on
session close -- entries are tiny and mutually exclusive).
Returns nil when bastion or host are still unknown."
  (let ((bastion emacs.d/vterm-bastion-name)
        (host    emacs.d/vterm-current-host)
        (user    emacs.d/vterm-current-user)
        (path    emacs.d/vterm-current-path))
    (when (and bastion host)
      (require 'tramp)
      (let* ((tramp-alias    (emacs.d/vterm--tramp-resolve-alias bastion))
             (sudo-user-name (emacs.d/vterm--tramp-resolved
                              bastion :sudo-user
                              emacs.d/vterm-tramp-sudo-user))
             (bastion-user   (emacs.d/vterm--tramp-resolved
                              bastion :bastion-user
                              emacs.d/vterm-tramp-bastion-user))
             (chain (emacs.d/vterm--tramp-chain
                     bastion tramp-alias host user path
                     sudo-user-name bastion-user)))
        (dolist (e (cdr chain))
          (add-to-list 'tramp-default-proxies-alist e))
        (car chain)))))

(defun emacs.d/vterm-update-current-host (&rest _ignored)
  "Refresh user/host/path from the prompt and rename tab + buffer, then
optionally sync `default-directory' to the matching TRAMP path.
The tab name only tracks the *host* (stable identity of the SSH
session), the buffer name additionally reflects the *cwd*, and the
TRAMP-derived `default-directory' also tracks the current *user* --
in increasing order of volatility.  Hooked as `:after' advice on
`vterm--filter'."
  (when (derived-mode-p 'vterm-mode)
    (let* ((ctx      (emacs.d/vterm-extract-prompt-context))
           (new-user (nth 0 ctx))
           (new-host (nth 1 ctx))
           (new-path (nth 2 ctx)))
      (when new-host
        (let ((host-changed (not (equal new-host emacs.d/vterm-current-host)))
              (user-changed (not (equal new-user emacs.d/vterm-current-user)))
              (path-changed (not (equal new-path emacs.d/vterm-current-path))))
          (when host-changed (setq-local emacs.d/vterm-current-host new-host))
          (when user-changed (setq-local emacs.d/vterm-current-user new-user))
          (when path-changed (setq-local emacs.d/vterm-current-path new-path))
          (when (and emacs.d/vterm-tab-name
                     (or host-changed user-changed path-changed))
            (let* ((bastion      emacs.d/vterm-bastion-name)
                   (new-tab-name (if bastion
                                     (format "%s: %s" bastion new-host)
                                   new-host))
                   (new-buf-name (emacs.d/vterm--compose-buffer-name
                                  new-tab-name new-path)))
              (when (and (bound-and-true-p tab-bar-mode)
                         (not (string-equal new-tab-name
                                            emacs.d/vterm-tab-name))
                         (emacs.d/tab-bar-rename-tab-by-name
                          emacs.d/vterm-tab-name new-tab-name))
                (setq-local emacs.d/vterm-tab-name new-tab-name))
              (unless (string-equal new-buf-name (buffer-name))
                ;; `t' makes the new name unique on collision (e.g. two
                ;; sessions land on the same alias + cwd at once).
                (rename-buffer new-buf-name t))
              (when emacs.d/vterm-tramp-auto-sync
                (when-let ((td (emacs.d/vterm--tramp-default-directory)))
                  (unless (string-equal td default-directory)
                    (setq-local default-directory td)))))))))))

(defun emacs.d/vterm--cross-to-remote (command)
  "Run COMMAND interactively with `default-directory' bound to the
session's TRAMP path when known.  Falls back to the buffer's
existing `default-directory' (local on plain vterms, already the
TRAMP path on session vterms with auto-sync enabled).  Reports in
the echo area when the fallback kicks in."
  (let* ((td (emacs.d/vterm--tramp-default-directory))
         (default-directory (or td default-directory)))
    (unless td
      (message "vterm: no remote target -- %s rooted at %s"
               command default-directory))
    (call-interactively command)))

* SSH sessions                                                :SESSIONS:
:PROPERTIES:
:CUSTOM_ID: ssh-sessions
:END:

A small launcher that spawns SSH connections inside [[#terminal][vterm + tab-bar]],
inspired by the saved-session lists of MobaXterm, Termius or PuTTY.

The connection method is plain ~ssh~ inside vterm, *not* TRAMP.  The
real-life flow involves CyberArk PSMP and other interactive prompts
(MFA, password change, banner acknowledgements) that don't fit
TRAMP's model; we want the saving in not having to remember the
host, user and port -- not in trying to script the credentials.

** Single source of truth: =~/.ssh/config=
:PROPERTIES:
:CUSTOM_ID: ssh-sessions-source
:END:

There is no Emacs-specific session storage.  The candidate list comes
straight from your OpenSSH client config, exactly the same file used
by ~ssh~, ~scp~, ~rsync~, ~git~, TRAMP and every other tool on the
system.  Adding a host once teaches every client at the same time.

How the parser works:

- All ~Host~ stanzas in =~/.ssh/config= are scanned.
- Each token on a ~Host~ line is treated as one alias, so
  =Host alias1 alias2= contributes both names.
- Tokens containing ~*~, ~?~ or ~!~ are skipped: these are /patterns/,
  not connectable aliases.  They keep applying transparently when you
  do connect (e.g. an ~IdentityFile~ under ~Host lx*~ is honoured for
  any =lx...= you type), but they should not appear as picker entries.
- ~Include~ directives are not followed -- if you split your config
  across files, point the defcustom ~emacs.d/ssh-config-file~ at the
  master one or extend the parser.

The picker accepts free-form input: typing a host that isn't in the
list (a brand-new alias, an IP, a Hostname-like string) connects
through ~ssh~ all the same.  Any ~Host *~ defaults you have set still
apply.  This makes "try a new host quickly" a one-keystroke flow.

Keep your bastion ssh_config entries *clean* -- no ~RemoteCommand~,
no ~RequestTTY~.  Those settings interfere with TRAMP's prompt
detection (and also block the multi-step chain this module
synthesises in shell), so we move all the "auto-elevate after
login" logic to Emacs.  A typical bastion entry looks like:

#+begin_src conf-space :tangle no
Host lxsag811 kxsag011 lxsag012
    HostName     psmpcyb.gbm.lan
    User         matteo.aquino@CYB-ADMIN1@%n.gbm.lan
    IdentityFile ~/.ssh/id_acme
    PreferredAuthentications publickey,keyboard-interactive
    # no RemoteCommand, no RequestTTY -- both vterm and TRAMP friendly
#+end_src

** Routing through a bastion (user@host)
:PROPERTIES:
:CUSTOM_ID: ssh-sessions-routing
:END:

The picker accepts two input shapes:

- *bare alias*  -- e.g. =lxsag811=, =zero=, =vps1=.  Direct =ssh -t alias=.
- *user@host*   -- e.g. =oracle@lxumc811=, =root@lxohr002=.  If the
  host part matches an entry in ~emacs.d/ssh-target-bastions~ the
  connection is routed through the configured bastion and the
  resulting vterm command is the multi-step chain a sysadmin would
  otherwise type by hand:

  #+begin_example
  ssh -t BASTION sudo -i -u SUDO-USER ssh -t TARGET sudo -i -u USER
  #+end_example

  where ~SUDO-USER~ comes from ~emacs.d/ssh-host-tramp-config~
  (default ~root~), the second =ssh= is skipped when ~TARGET~ equals
  ~BASTION~, and the trailing ~sudo~ is skipped when ~USER~ already
  matches the post-elevation identity.  Free input still works for
  one-off connections to hosts that don't need any of this.

The same ~emacs.d/ssh-host-tramp-config~ that drives the [[#terminal-tramp][TRAMP
path tracking]] is consulted to find the bastion's elevation
settings; one source of truth covers both the vterm chain and the
TRAMP chain.

Example -- two bastions chosen by the host-name *digit group* (the
first digit after the alpha prefix selects the data-centre / row,
so `lxumc811' belongs to the 8xx world routed through `lxsag811',
whereas `lxohr002' is in the 0xx world routed through `lxsag011'):

#+begin_src emacs-lisp :tangle no
(setq emacs.d/ssh-host-tramp-config
      '(("\\`\\(lx\\|kx\\)sag" :sudo-user "root")))

(setq emacs.d/ssh-target-bastions
      '(("\\`lx[a-z]+0[0-9]"     . "lxsag011")
        ("\\`lx[a-z]+[789][0-9]" . "lxsag811")))
#+end_src

Then ~C-c s s oracle@lxumc811~ opens a vterm running
=ssh -t lxsag811 sudo -i -u root ssh -t lxumc811 sudo -i -u oracle=,
~C-c s s root@lxohr002~ uses =lxsag011= instead, and `C-c f' / `C-c
d' inside each vterm reach the same file-system view via TRAMP --
all from one ~setq~ pair.

| Key       | Command                     | Purpose                                                           |
|-----------+-----------------------------+-------------------------------------------------------------------|
| ~C-c s s~ | ~emacs.d/ssh-sessions-open~ | Pick a host or =user@host= and open it in a new tab               |
| ~C-c s a~ | ~emacs.d/ssh-sessions-add~  | Append a ~Host~ scaffold at the end of =~/.ssh/config=, point ready |
| ~C-c s e~ | ~emacs.d/ssh-sessions-edit~ | Open =~/.ssh/config= for free-form editing                          |

The "add" command is intentionally ergonomic-but-undoable: it inserts
a commented template, leaves point right after ~Host~, and trusts the
user to either fill it in and save -- or close the buffer without
saving to discard the scaffold entirely.

** Lifecycle
:PROPERTIES:
:CUSTOM_ID: ssh-sessions-lifecycle
:END:

Opening a session:

1. Creates a new tab and renames it to the picker input
   /immediately/, so the label is visible before SSH has even
   authenticated.
2. Spawns a vterm whose shell is either ~ssh -t HOST~ or the routed
   multi-step chain described above.
3. Pre-seeds ~emacs.d/vterm-bastion-name~ to the resolved bastion
   alias (or the host itself for direct connections), so the TRAMP
   default-directory sync can start composing the right chain as
   soon as the prompt parser yields a host.
4. Installs the buffer-local ~kill-buffer-hook~ that closes the tab
   when the session is killed (see [[#terminal-closing][Closing sessions]]).

;;; setup-ssh-sessions.el --- Open SSH connections in vterm tabs -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "SSH sessions".

;;; Code:

(require 'cl-lib)
(require 'subr-x)
(require 'tab-bar)

(defcustom emacs.d/ssh-config-file
  (expand-file-name "~/.ssh/config")
  "OpenSSH client configuration file used as the source of host aliases."
  :type 'file :group 'emacs.d)

(defcustom emacs.d/ssh-target-bastions nil
  "Alist mapping target-host regexps to the bastion ssh_config alias
to route through.  Each entry is `(REGEX . BASTION-ALIAS)' where
REGEX is matched against the host name (the part after `@' in
`user@host' notation, or the bare host name) given to
`emacs.d/ssh-sessions-open'.  First match wins.

When you open a session for a target matched here, instead of
`ssh -t target' the command is built as

    ssh -t BASTION sudo -i -u SUDO-USER ssh -t TARGET [sudo -i -u USER]

mirroring the manual sequence a sysadmin would type by hand.  The
bastion's per-host settings (sudo-user, tramp-alias) come from
`emacs.d/ssh-host-tramp-config'.  Targets that match no entry use
plain `ssh' as before.

Example:

  \\='((\"\\\\`lx\\\\(umc\\\\|ohr\\\\|wfm\\\\)\" . \"lxsag811\"))"
  :type '(alist :key-type regexp :value-type string)
  :group 'emacs.d)

(defun emacs.d/ssh-sessions--parse-aliases (file)
  "Return concrete host aliases declared in FILE, omitting wildcards.
Patterns containing `*', `?' or `!' are skipped: they are matched by
ssh at connect time but cannot themselves be connected to, so they
must not appear as picker candidates."
  (when (file-readable-p file)
    (let (aliases)
      (with-temp-buffer
        (insert-file-contents file)
        (goto-char (point-min))
        (while (re-search-forward
                "^[ \t]*Host[ \t]+\\(.+?\\)[ \t]*$" nil t)
          (dolist (token (split-string (match-string 1) "[ \t]+" t))
            (unless (string-match-p "[*?!]" token)
              (push token aliases)))))
      (delete-dups (nreverse aliases)))))

(defun emacs.d/ssh-sessions--parse-input (input)
  "Parse INPUT into (USER . HOST), with USER nil if not given."
  (if (string-match "\\`\\([^@]+\\)@\\(.+\\)\\'" input)
      (cons (match-string 1 input) (match-string 2 input))
    (cons nil input)))

(defun emacs.d/ssh-sessions--bastion-for (host)
  "Return the bastion alias to route HOST through, or nil if HOST
doesn't match anything in `emacs.d/ssh-target-bastions'."
  (cdr (cl-find-if (lambda (entry) (string-match-p (car entry) host))
                   emacs.d/ssh-target-bastions)))

(defun emacs.d/ssh-sessions--build-command (user host bastion)
  "Return the shell command to open the session described by USER, HOST
and BASTION (may be nil for direct connections).

When BASTION is nil: a plain `ssh -t [USER@]HOST'.

When BASTION is set, synthesise the multi-step chain a human would
type by hand: ssh to the bastion, sudo -i to the bastion's SUDO-USER
(from `emacs.d/ssh-host-tramp-config'; default `root'), optionally
ssh again to HOST when it is not the bastion itself, and finally
sudo to USER when USER is given and differs from the post-elevation
identity.

The interactive ssh_config Host stanza of BASTION must NOT carry
`RemoteCommand' or `RequestTTY' settings: this function appends the
elevation steps via shell, and any RemoteCommand would either
double-elevate or hijack the chain.  Use `emacs.d/ssh-host-tramp-config'
to point TRAMP at a separate clean alias if your interactive entry
must keep those settings for legacy CLI workflows."
  (if (not bastion)
      (cond
       (user (format "ssh -t %s@%s" user host))
       (t    (format "ssh -t %s" host)))
    (let* ((sudo-user    (emacs.d/vterm--tramp-resolved
                          bastion :sudo-user
                          (bound-and-true-p emacs.d/vterm-tramp-sudo-user)))
           (bastion-user (emacs.d/vterm--tramp-resolved
                          bastion :bastion-user
                          (or (bound-and-true-p emacs.d/vterm-tramp-bastion-user)
                              "root")))
           (parts (list (format "ssh -t %s" bastion))))
      (when sudo-user
        (setq parts (append parts (list (format "sudo -i -u %s" sudo-user)))))
      (unless (string-equal host bastion)
        (setq parts (append parts (list (format "ssh -t %s" host)))))
      (when (and user
                 (not (string-equal user (or sudo-user bastion-user))))
        (setq parts (append parts (list (format "sudo -i -u %s" user)))))
      (mapconcat #'identity parts " "))))

;;;###autoload
(defun emacs.d/ssh-sessions-open (input)
  "Open an SSH session in a fresh vterm tab.

INPUT is read from the minibuffer and may take two shapes:

- a bare alias        => direct `ssh -t ALIAS'.  Candidates come
                         from `emacs.d/ssh-config-file' (free text
                         accepted too, so a brand-new alias / IP
                         connects without ceremony).

- `user@host'         => if HOST matches `emacs.d/ssh-target-bastions',
                         the connection is routed through the bastion
                         (with auto sudo elevation declared in
                         `emacs.d/ssh-host-tramp-config') and ends as
                         USER on HOST.  Otherwise: plain `ssh -t user@host'.

Buffer-local state is primed so the TRAMP `default-directory'
auto-sync (in setup-terminal) finds the right bastion as soon as
the prompt parser yields a host."
  (interactive
   (let ((aliases (emacs.d/ssh-sessions--parse-aliases
                   emacs.d/ssh-config-file)))
     (list (completing-read "SSH host (or user@host): " aliases nil nil))))
  (when (string-empty-p input)
    (user-error "No host given"))
  (pcase-let* ((`(,user . ,host) (emacs.d/ssh-sessions--parse-input input))
               (bastion          (emacs.d/ssh-sessions--bastion-for host))
               (cmd     (emacs.d/ssh-sessions--build-command user host bastion))
               (label   input)
               (buf-name (format "*ssh: %s*" label)))
    (tab-bar-new-tab)
    (tab-bar-rename-tab label)

    (require 'vterm)
    (let ((vterm-shell       cmd)
          (vterm-buffer-name buf-name))
      (vterm vterm-buffer-name))

    (with-current-buffer (current-buffer)
      ;; Pre-seed buffer-local state so TRAMP `default-directory'
      ;; auto-sync (in setup-terminal) lands on the right hop chain
      ;; even before the prompt parser has caught the first prompt.
      ;; Stop vterm from renaming the buffer on OSC title escapes:
      ;; setup-terminal already does it from the prompt regex, and
      ;; two competing renamers would race.
      (setq-local emacs.d/vterm-bastion-name (or bastion host)
                  emacs.d/vterm-tab-name     label
                  vterm-buffer-name-string   nil)
      (add-hook 'kill-buffer-hook
                #'emacs.d/vterm-close-tab-on-kill nil t))

    (force-mode-line-update t)))

(defun emacs.d/ssh-sessions-add ()
  "Append a `Host' template at the end of `emacs.d/ssh-config-file'.
Point lands right after `Host ', ready for the alias name.  The
template lines are pre-inserted but mostly commented out -- save to
keep, kill the buffer without saving to discard the scaffold entirely."
  (interactive)
  (find-file emacs.d/ssh-config-file)
  (goto-char (point-max))
  (unless (bolp) (insert "\n"))
  (let ((stanza-start (point)))
    (insert "\nHost \n"
            "    HostName \n"
            "    User \n"
            "    # Port 22\n"
            "    # IdentityFile ~/.ssh/id_rsa\n"
            "    # ProxyJump some-bastion\n")
    (goto-char stanza-start)
    (forward-line 1)
    (end-of-line)))

* SSH tunnels                                                  :TUNNELS:
:PROPERTIES:
:CUSTOM_ID: ssh-tunnels
:END:

A small manager for SSH port-forwarding tunnels.  Mental model:
"MobaXterm's tunnel list" living in an Emacs buffer with explicit
on/off toggles.

Tunnels run as native Emacs subprocesses (no shell wrapper), so they
die cleanly when Emacs exits and their stderr is captured in
=*ssh-tunnel: NAME*= buffers if anything goes wrong.  Each ssh
invocation is run with ~-N -T~ (no remote shell, no PTY) plus
~ServerAliveInterval=30~, ~ServerAliveCountMax=3~ and
~ExitOnForwardFailure=yes~ -- helpful behind CyberArk PSMP and other
corporate firewalls that idle-kill connections silently.

** Storage and schema
:PROPERTIES:
:CUSTOM_ID: ssh-tunnels-schema
:END:

Tunnels live in =var/ssh-tunnels.el= (gitignored).  Each entry is a
plist; the file contains a single Lisp form -- a list of plists.

| Field          | Required          | Meaning                                                |
|----------------+-------------------+--------------------------------------------------------|
| ~:name~        | yes               | Unique label.                                          |
| ~:type~        | yes               | One of ~local~, ~remote~, ~dynamic~.                   |
| ~:local-port~  | yes               | Local TCP port (or, for ~dynamic~, the SOCKS port).    |
| ~:remote-host~ | local / remote    | Hostname /as seen from the bastion/.  Ignored for ~dynamic~. |
| ~:remote-port~ | local / remote    | TCP port on the remote host.  Ignored for ~dynamic~.   |
| ~:via-host~    | yes               | The SSH host through which the tunnel is opened.       |
| ~:via-user~    | no                | Username for the SSH connection.                       |
| ~:description~ | no                | Free-form note.                                        |

Type semantics (mirrors the OpenSSH manual):

- ~local~  → ~ssh -L LP:RH:RP user@VIA~  (forward a local port to a remote address through the bastion)
- ~remote~ → ~ssh -R LP:RH:RP user@VIA~  (forward a remote port back to a local address)
- ~dynamic~ → ~ssh -D LP user@VIA~  (turn the bastion into a SOCKS proxy on local port LP)

Example:

#+begin_src emacs-lisp :tangle no
(:name        "weblogic-prod-console"
 :type        local
 :local-port  7001
 :remote-host "weblogic.internal.acme"
 :remote-port 7001
 :via-host    "bastion.acme.com"
 :via-user    "myuser"
 :description "Open http://localhost:7001/console")
#+end_src

;;; setup-ssh-tunnels.el --- SSH tunnel manager -*- lexical-binding: t; -*-

;;; Commentary:

(require 'cl-lib)
(require 'subr-x)
(require 'tabulated-list)

(defcustom emacs.d/ssh-tunnels-file
  (expand-file-name "var/ssh-tunnels.el" user-emacs-directory)
  "File where SSH tunnel definitions are persisted."
  :type 'file :group 'emacs.d)

(defvar emacs.d/ssh-tunnels nil
  "In-memory list of SSH tunnel plists.")

(defvar emacs.d/ssh-tunnels--processes (make-hash-table :test 'equal)
  "Map of tunnel-name -> live `process' object for active tunnels.")

(defun emacs.d/ssh-tunnels--seed-file (file)
  "Write a starter list with one example tunnel to FILE."
  (make-directory (file-name-directory file) t)
  (with-temp-file file
    (insert ";; -*- lexical-binding: t; -*-\n"
            ";; SSH tunnels for `setup-ssh-tunnels'.\n"
            ";; Each entry is a plist; see config.org for the schema.\n\n"
            "(\n"
            "  (:name \"example-weblogic-console\"\n"
            "   :type local\n"
            "   :local-port 7001\n"
            "   :remote-host \"weblogic.internal.example.com\"\n"
            "   :remote-port 7001\n"
            "   :via-host \"bastion.example.com\"\n"
            "   :via-user \"myuser\"\n"
            "   :description \"http://localhost:7001/console\")\n"
            ")\n")))

(defun emacs.d/ssh-tunnels-load ()
  "Load `emacs.d/ssh-tunnels' from `emacs.d/ssh-tunnels-file'."
  (let ((file emacs.d/ssh-tunnels-file))
    (unless (file-exists-p file)
      (emacs.d/ssh-tunnels--seed-file file))
    (with-temp-buffer
      (insert-file-contents file)
      (goto-char (point-min))
      (setq emacs.d/ssh-tunnels (read (current-buffer))))))

(defun emacs.d/ssh-tunnels-save ()
  "Write `emacs.d/ssh-tunnels' back to disk as pretty-printed Lisp."
  (let ((file emacs.d/ssh-tunnels-file))
    (make-directory (file-name-directory file) t)
    (with-temp-file file
      (insert ";; -*- lexical-binding: t; -*-\n"
              ";; SSH tunnels for `setup-ssh-tunnels'.\n\n")
      (let ((print-length nil) (print-level nil))
        (pp emacs.d/ssh-tunnels (current-buffer))))))

(defun emacs.d/ssh-tunnels--ensure-loaded ()
  (unless emacs.d/ssh-tunnels (emacs.d/ssh-tunnels-load)))

(defun emacs.d/ssh-tunnels--find (name)
  (cl-find name emacs.d/ssh-tunnels
           :key  (lambda (tunnel) (plist-get tunnel :name))
           :test #'string-equal))

(defun emacs.d/ssh-tunnels--running-p (name)
  (let ((proc (gethash name emacs.d/ssh-tunnels--processes)))
    (and proc (process-live-p proc))))

(defun emacs.d/ssh-tunnels--build-args (tunnel)
  "Return the argv (no program) to launch TUNNEL via ssh."
  (let* ((type   (plist-get tunnel :type))
         (lport  (plist-get tunnel :local-port))
         (rhost  (plist-get tunnel :remote-host))
         (rport  (plist-get tunnel :remote-port))
         (via    (plist-get tunnel :via-host))
         (user   (plist-get tunnel :via-user))
         (target (if user (format "%s@%s" user via) via)))
    (append
     '("-N" "-T")
     ;; Keepalive + fail-fast: helpful behind CyberArk PSMP and other
     ;; corporate firewalls that idle-kill connections silently.
     '("-o" "ServerAliveInterval=30"
       "-o" "ServerAliveCountMax=3"
       "-o" "ExitOnForwardFailure=yes")
     (cl-case type
       (local   (list "-L" (format "%d:%s:%d" lport rhost rport)))
       (remote  (list "-R" (format "%d:%s:%d" lport rhost rport)))
       (dynamic (list "-D" (format "%d" lport)))
       (t       (error "Unknown tunnel type: %S" type)))
     (list target))))

(defun emacs.d/ssh-tunnels--start (tunnel)
  "Spawn the ssh subprocess for TUNNEL and register its sentinel."
  (let* ((name (plist-get tunnel :name))
         (args (emacs.d/ssh-tunnels--build-args tunnel))
         (buf  (get-buffer-create (format "*ssh-tunnel: %s*" name)))
         (proc (apply #'start-process
                      (format "ssh-tunnel-%s" name)
                      buf
                      "ssh" args)))
    (puthash name proc emacs.d/ssh-tunnels--processes)
    (set-process-sentinel
     proc
     (lambda (p _event)
       (unless (process-live-p p)
         (remhash name emacs.d/ssh-tunnels--processes)
         (when (get-buffer "*ssh-tunnels*")
           (with-current-buffer "*ssh-tunnels*" (revert-buffer))))))
    (message "Tunnel %S started (pid %d)" name (process-id proc))))

(defun emacs.d/ssh-tunnels--stop (name)
  "Signal the live ssh process for tunnel NAME to terminate cleanly."
  (when-let ((proc (gethash name emacs.d/ssh-tunnels--processes)))
    (when (process-live-p proc)
      (interrupt-process proc)
      (run-at-time 0.5 nil
                   (lambda ()
                     (when (process-live-p proc)
                       (kill-process proc))))
      (message "Tunnel %S stopped" name))))

(defvar emacs.d/ssh-tunnels-list-mode-map
  (let ((map (make-sparse-keymap)))
    (set-keymap-parent map tabulated-list-mode-map)
    (define-key map (kbd "RET") #'emacs.d/ssh-tunnels-toggle)
    (define-key map (kbd "t")   #'emacs.d/ssh-tunnels-toggle)
    (define-key map (kbd "a")   #'emacs.d/ssh-tunnels-add)
    (define-key map (kbd "d")   #'emacs.d/ssh-tunnels-delete-at-point)
    (define-key map (kbd "e")   #'emacs.d/ssh-tunnels-edit)
    (define-key map (kbd "K")   #'emacs.d/ssh-tunnels-stop-all)
    (define-key map (kbd "g")   #'revert-buffer)
    map)
  "Keymap for `emacs.d/ssh-tunnels-list-mode'.")

(define-derived-mode emacs.d/ssh-tunnels-list-mode tabulated-list-mode
  "SSH-Tunnels"
  "Major mode for the SSH tunnels list."
  (setq tabulated-list-format
        [("●"           2  nil)
         ("Name"       24  t)
         ("Type"        8  t)
         ("Spec"       32  t)
         ("Via"        30  t)
         ("Description" 0  t)])
  (setq tabulated-list-padding 1
        tabulated-list-sort-key '("Name" . nil))
  (add-hook 'tabulated-list-revert-hook
            #'emacs.d/ssh-tunnels--refresh-entries nil t)

(defun emacs.d/ssh-tunnels--format-spec (tunnel)
  "Render a one-line forwarding spec for TUNNEL."
  (let ((type  (plist-get tunnel :type))
        (lport (plist-get tunnel :local-port))
        (rhost (plist-get tunnel :remote-host))
        (rport (plist-get tunnel :remote-port)))
    (cl-case type
      (local   (format "L %s -> %s:%s" lport rhost rport))
      (remote  (format "R %s -> %s:%s" lport rhost rport))
      (dynamic (format "D %s (SOCKS)"  lport))
      (t       "?"))))

(defun emacs.d/ssh-tunnels--refresh-entries ()
  (emacs.d/ssh-tunnels--ensure-loaded)
  (setq tabulated-list-entries
        (mapcar
         (lambda (tunnel)
           (let* ((name    (plist-get tunnel :name))
                  (type    (plist-get tunnel :type))
                  (via     (plist-get tunnel :via-host))
                  (user    (plist-get tunnel :via-user))
                  (descr   (or (plist-get tunnel :description) ""))
                  (running (emacs.d/ssh-tunnels--running-p name))
                  (dot     (if running
                               (propertize "●" 'face 'success)
                             (propertize "○" 'face 'shadow))))
             (list name
                   (vector dot
                           name
                           (symbol-name type)
                           (emacs.d/ssh-tunnels--format-spec tunnel)
                           (if user (format "%s@%s" user via) (or via ""))
                           descr))))
         emacs.d/ssh-tunnels)))

(defun emacs.d/ssh-tunnels--current-name ()
  (or (tabulated-list-get-id)
      (user-error "No tunnel on this line")))

(defun emacs.d/ssh-tunnels--refresh-list-buffer (&optional delay)
  "Schedule a refresh of the *ssh-tunnels* buffer if it exists."
  (when (get-buffer "*ssh-tunnels*")
    (run-at-time (or delay 0) nil
                 (lambda ()
                   (when (get-buffer "*ssh-tunnels*")
                     (with-current-buffer "*ssh-tunnels*"
                       (revert-buffer)))))))

(defun emacs.d/ssh-tunnels-toggle ()
  "Toggle the tunnel on the current row on/off."

         (tunnel (emacs.d/ssh-tunnels--find name)))
    (unless tunnel (user-error "Tunnel %S not found" name))
    (if (emacs.d/ssh-tunnels--running-p name)
        (emacs.d/ssh-tunnels--stop name)

    (emacs.d/ssh-tunnels--refresh-list-buffer 0.2)))

(defun emacs.d/ssh-tunnels-add ()
  "Interactively define a new tunnel and persist it."
  (interactive)
  (emacs.d/ssh-tunnels--ensure-loaded)
  (let ((name (read-string "Tunnel name (unique): ")))
    (when (emacs.d/ssh-tunnels--find name)
      (user-error "A tunnel named %S already exists" name))
    (let* ((type  (intern (completing-read "Type: "
                                           '("local" "remote" "dynamic")
                                           nil t "local")))
           (lport (read-number "Local port: " 8080))
           (rhost (unless (eq type 'dynamic)
                    (read-string "Remote host (as seen from the bastion): ")))
           (rport (unless (eq type 'dynamic)
                    (read-number "Remote port: " 80)))
           (via   (read-string "Via SSH host (the bastion): "))
           (user  (let ((u (read-string "Via SSH user (RET to skip): ")))
                    (and (not (string-empty-p u)) u)))
           (descr (let ((d (read-string "Description (RET to skip): ")))
                    (and (not (string-empty-p d)) d)))
           (tunnel (apply #'list
                          :name name :type type :local-port lport
                          (append
                           (when rhost (list :remote-host rhost))
                           (when rport (list :remote-port rport))
                           (list :via-host via)
                           (when user  (list :via-user user))
                           (when descr (list :description descr))))))
      (setq emacs.d/ssh-tunnels (append emacs.d/ssh-tunnels (list tunnel)))
      (emacs.d/ssh-tunnels-save)
      (emacs.d/ssh-tunnels--refresh-list-buffer)
      (message "Tunnel %S saved." name))))

(defun emacs.d/ssh-tunnels-delete-at-point ()
  "Delete the tunnel on the current row from the saved list."
  (interactive)
  (let ((name (emacs.d/ssh-tunnels--current-name)))
    (when (yes-or-no-p (format "Really delete tunnel %S? " name))
      (emacs.d/ssh-tunnels--stop name)
      (setq emacs.d/ssh-tunnels
            (cl-remove-if (lambda (tunnel)
                            (string-equal name (plist-get tunnel :name)))
                          emacs.d/ssh-tunnels))
      (emacs.d/ssh-tunnels-save)
      (revert-buffer))))

(defun emacs.d/ssh-tunnels-stop-all ()
  "Stop every currently-active tunnel after confirmation."
  (interactive)
  (let ((names (hash-table-keys emacs.d/ssh-tunnels--processes)))
    (when (and names
               (yes-or-no-p
                (format "Stop %d active tunnel(s)? " (length names))))
      (mapc #'emacs.d/ssh-tunnels--stop names))
    (emacs.d/ssh-tunnels--refresh-list-buffer)))

(defun emacs.d/ssh-tunnels--reload-after-save ()
  "Buffer-local `after-save-hook' for the storage file: reload tunnels."
  (when (and buffer-file-name
             (string-equal (expand-file-name buffer-file-name)
                           (expand-file-name emacs.d/ssh-tunnels-file)))
    (emacs.d/ssh-tunnels-load)
    (emacs.d/ssh-tunnels--refresh-list-buffer)
    (message "Tunnels reloaded (%d entries)."
             (length emacs.d/ssh-tunnels))))

;;;###autoload
(defun emacs.d/ssh-tunnels-edit ()
  "Open the tunnel storage file for direct Lisp editing."
  (interactive)
  (emacs.d/ssh-tunnels--ensure-loaded)
  (find-file emacs.d/ssh-tunnels-file)
  (add-hook 'after-save-hook #'emacs.d/ssh-tunnels--reload-after-save nil t))
