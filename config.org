* About
:PROPERTIES:
:CUSTOM_ID: about
:END:

This is a /literate/ Emacs configuration: prose and source code live
together in this file, and Org Babel /tangles/ each ~src~ block out
into the corresponding ~.el~ file under [[file:lisp/][lisp/]].

The intent is a clean separation of concerns:

- *This document* holds the explanation: what each module is for, why
  the non-default knobs are turned, where to find more, install
  recipes, key bindings.
- *The tangled ~.el~ files* hold only the code -- short comments where
  the WHY is non-obvious, function docstrings where Emacs uses them,
  and nothing else.

** Workflow
:PROPERTIES:
:CUSTOM_ID: workflow
:END:

Editing this file and saving it triggers an ~after-save-hook~ that
re-tangles every ~src~ block into its target ~.el~ file.  Editing a
~.el~ directly is supported but the prose here will then drift out of
date -- prefer making non-trivial changes through the org file.

** First run on a new machine
:PROPERTIES:
:CUSTOM_ID: first-run
:END:

~git clone~ + ~emacs~.  The bootstrap in ~init.el~ adds ~lisp/~ to
~load-path~, configures three package archives (GNU ELPA, NonGNU ELPA,
MELPA), and ~require~'s each module in turn.  Missing third-party
packages are downloaded by ~use-package~ on first start; language
servers, the vterm C module, and a handful of optional CLI tools are
installed manually -- see [[#prog][Programming language support]] and
[[#terminal][Terminal]].

* early-init.el                                                   :EARLY:
:PROPERTIES:
:CUSTOM_ID: early-init
:END:

[[file:early-init.el][~early-init.el~]] runs /before/ ~package.el~ is initialised and /before/
any frame is painted.  It is intentionally minimal: only those things
that have to happen *that* early go here.

- *GC tuning during boot.*  The default ~gc-cons-threshold~ (≈800 KiB)
  causes the collector to fire dozens of times while loading Lisp.  We
  raise the threshold to ~most-positive-fixnum~ (effectively "do not
  GC during init") and bump ~gc-cons-percentage~; an
  ~emacs-startup-hook~ resets both to sane runtime values.  At runtime
  ~gcmh-mode~ (loaded from [[#memory][Memory and GC]]) takes over to keep the
  threshold high while busy and low when idle.

- *Disable file-name handlers during init.*  Every ~load~ walks
  ~file-name-handler-alist~ looking for a handler that matches the
  path (TRAMP, jka-compr, archive-mode, ...).  We empty the alist for
  the duration of the boot and restore it afterwards.

- *Hide chrome before the first paint.*  Toolbar, menubar and
  scrollbar are turned off here so the user never sees them flash on
  screen.  Skip the splash and the chatty ~*scratch*~ header for the
  same reason.

- *Take ownership of package activation.*
  ~package-enable-at-startup~ defaults to ~t~, meaning Emacs activates
  every installed package between early-init.el and init.el.  We turn
  it off so ~init.el~ can call ~package-initialize~ at the exact point
  it wants -- after archive priorities and other knobs are set.

- *Quiet native compilation warnings.*  Useful when debugging an elisp
  package, noisy for end users; warnings still go to ~*Warnings*~,
  they just no longer steal focus.

This file is /not/ tangled from the org document -- ~early-init.el~
must exist on disk before Org has had a chance to load.

* Init bootstrap
:PROPERTIES:
:CUSTOM_ID: init
:END:

[[file:init.el][~init.el~]] is the bootstrap entry point and stays small.  Its
responsibilities, in order:

1. *Refuse to start on Emacs < 29.1.*  This config relies on
   ~use-package~, ~eglot~, ~flymake~, tree-sitter and ~which-key~ all
   being built in.  Failing fast with a clear message is friendlier
   than letting the user debug obscure errors later.

2. *Set up ~load-path~ and ~custom-file~.*  ~lisp/~ is prepended to
   ~load-path~; the custom file is redirected to ~custom.el~ (kept
   out of the repo via ~.gitignore~) so interactive ~customize-*~
   never edits ~init.el~.

3. *Configure package archives.*  We pull from GNU ELPA, NonGNU ELPA
   and MELPA, with descending priorities -- GNU first, MELPA last --
   to avoid surprise breakages from MELPA's "always-latest" policy
   when the same package is also in a stable archive.

4. *Disable the Emacs 30 ~compat~ stub.*  Emacs 30 ships a placeholder
   ~lisp/emacs-lisp/compat.el~ that registers the package as built-in
   to stop legacy ~(require 'compat)~ failing.  The stub does not
   contain recent additions like ~static-when~ that modern transient
   (≥ 0.13) and magit (≥ 4.5) need.  We unregister it from
   ~package--builtins~ / ~package--builtin-versions~ so
   ~package-install~ fetches the real GNU ELPA ~compat~.  Symptoms of
   not having this fix: ~void-function static-when~ at runtime, or
   ~transient--init-suffix-key is already defined as something else
   than a generic function~ during byte-compilation.

5. *Refresh archive metadata when stale.*  MELPA / NonGNU prune old
   tarballs as new versions ship.  A metadata snapshot taken weeks
   ago can point to versions that no longer exist on the server,
   producing the classic ~Not found~ error.  We detect a stale local
   cache (older than ~emacs.d/package-refresh-stale-days~, default 7)
   and refresh transparently.

6. *Initialise ~use-package~* with sensible defaults.

7. *Re-tangle ~config.org~ on demand.*  If the org file is newer than
   any module under ~lisp/~ we tangle it before requiring the
   modules.  Together with the editor-side ~after-save-hook~, this
   means edits to ~config.org~ are always reflected in the loaded
   modules without manual intervention.

8. *Require modules in dependency order.*  Memory first (gcmh tunes
   the GC during the rest of the load), UI second (theme + font
   should be in place while later modules report messages), then
   editor, completion, programming, magit, tramp, terminal, sessions,
   tunnels.

This file is /not/ tangled either -- it is the bootstrap.

* Memory and GC                                                  :MEMORY:
:PROPERTIES:
:CUSTOM_ID: memory
:END:

Three layers cooperate to keep Emacs responsive without holding more
RAM than necessary:

1. [[https://gitlab.com/koral/gcmh][gcmh]] raises the GC threshold while you are typing or scrolling
   and lowers it during idle time -- the inverse of the default
   behaviour, which tends to fire the GC right when you press a key.

2. ~read-process-output-max~ is bumped to 1 MiB so LSP servers can
   deliver hundreds of KiB of JSON in a single read instead of many
   small ones (each of which would trigger redisplay).
   ~process-adaptive-read-buffering~ is disabled for the same reason
   -- LSP wants data fast, not "smooth".

3. ~history-*~, ~kill-ring-max~, ~undo-*~ and
   ~large-file-warning-threshold~ are raised to numbers that match
   what modern hardware can comfortably hold.  Notably ~undo-limit~
   defaults silently truncate the history of files larger than ~150
   KiB; bumping the limits costs a handful of MiB and prevents an
   unpleasant surprise on long editing sessions.

#+begin_src emacs-lisp :tangle lisp/setup-memory.el
;;; setup-memory.el --- GC and memory tuning -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Memory and GC".

;;; Code:

(use-package gcmh
  :diminish gcmh-mode
  :init
  (setq gcmh-idle-delay              'auto
        gcmh-auto-idle-delay-factor  10
        gcmh-high-cons-threshold     (* 16 1024 1024))
  :hook (emacs-startup . gcmh-mode))

(setq read-process-output-max         (* 1024 1024)
      process-adaptive-read-buffering nil)

(setq history-length            1000
      history-delete-duplicates t
      kill-ring-max             300
      mark-ring-max             50
      global-mark-ring-max      50)

(setq undo-limit          (* 4  1024 1024)
      undo-strong-limit   (* 6  1024 1024)
      undo-outer-limit    (* 64 1024 1024))

(setq large-file-warning-threshold (* 100 1024 1024))

(provide 'setup-memory)
;;; setup-memory.el ends here
#+end_src

* Look and feel                                                      :UI:
:PROPERTIES:
:CUSTOM_ID: ui
:END:

Visual choices: a dark, low-saturation theme; a font cascade that
falls back gracefully on machines without the preferred face; smooth
modern scrolling; line numbers and current-line highlight in
~prog-mode~ only.

** Theme
:PROPERTIES:
:CUSTOM_ID: theme
:END:

[[https://github.com/rexim/gruber-darker-theme][gruber-darker]] is the choice -- muted, easy on the eyes for long
sessions.

Emacs 30 tightened ~set-face-attribute~ validation: passing ~nil~ as
the value for ~:background~ / ~:foreground~ / ~:underline~ /
~:overline~ now triggers a warning.  Older themes (gruber-darker
included) still pass ~nil~ to mean "no override"; the modern way to
spell that is the symbol ~unspecified~.  An ~:around~ advice on
~set-face-attribute~ rewrites those four colour-like attributes from
~nil~ to ~unspecified~, silencing the warnings without changing the
theme's intent.

** Font cascade
:PROPERTIES:
:CUSTOM_ID: font
:END:

~emacs.d/font-candidates~ is a customisable, ranked list of font
names; the first one actually installed on the machine wins.  Default
ranking starts with /Comic Code Ligatures/ and falls back through
Iosevka, JetBrains Mono, Fira Code, Cascadia Code, DejaVu Sans Mono,
so the same configuration boots cleanly anywhere.  Height is
controlled by ~emacs.d/font-height~ (units are 1/10 of a point, so
220 = 22pt).

** Scrolling and parens
:PROPERTIES:
:CUSTOM_ID: scrolling
:END:

Default scrolling recenters the point when it falls off-screen --
jarring, and unlike any other modern editor.  We set
~scroll-conservatively~, a 3-line top/bottom margin, preserve screen
position, and turn on pixel-precise trackpad scrolling on Emacs 29+.
Matching parens are highlighted with zero delay.

The frame title shows the path of the visited file (or the buffer
name for non-file buffers) so alt-tabbing between Emacs frames works
intuitively.

#+begin_src emacs-lisp :tangle lisp/setup-ui.el
;;; setup-ui.el --- Theme, font, scrolling, line numbers -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Look and feel".

;;; Code:

(require 'cl-lib)

(defun emacs.d/face-attribute-rewrite-nil (orig-fn face frame &rest props)
  "Translate nil to `unspecified' for colour-like face attributes.

Older themes still pass nil to mean \"no override\"; Emacs 30 emits a
warning in that case.  Used as `:around' advice on
`set-face-attribute'."
  (let ((rewritten
         (cl-loop for (k v) on props by #'cddr
                  append (list k
                               (if (and (memq k '(:background :foreground
                                                  :underline  :overline))
                                        (null v))
                                   'unspecified
                                 v)))))
    (apply orig-fn face frame rewritten)))

(advice-add 'set-face-attribute :around
            #'emacs.d/face-attribute-rewrite-nil)

(use-package gruber-darker-theme
  :config (load-theme 'gruber-darker :no-confirm))

(defcustom emacs.d/font-candidates
  '("Comic Code Ligatures"
    "Comic Code"
    "Iosevka"
    "JetBrains Mono"
    "Fira Code"
    "Cascadia Code"
    "DejaVu Sans Mono")
  "Ranked list of fixed-pitch fonts to try, first installed wins."
  :type '(repeat string)
  :group 'emacs.d)

(defcustom emacs.d/font-height 220
  "Height (1/10 of a point) for the default face."
  :type 'integer :group 'emacs.d)

(defun emacs.d/first-installed-font (candidates)
  "Return the first font in CANDIDATES that is installed, or nil."
  (seq-find (lambda (f) (find-font (font-spec :name f))) candidates))

(when-let ((font (emacs.d/first-installed-font emacs.d/font-candidates)))
  (set-face-attribute 'default nil :font font :height emacs.d/font-height))

(add-hook 'prog-mode-hook #'display-line-numbers-mode)
(add-hook 'prog-mode-hook #'hl-line-mode)
(setq display-line-numbers-width-start t)
(column-number-mode 1)
(line-number-mode   1)

(setq scroll-conservatively           101
      scroll-margin                   3
      scroll-preserve-screen-position t
      auto-window-vscroll             nil)

(when (fboundp 'pixel-scroll-precision-mode)
  (pixel-scroll-precision-mode 1))

(setq show-paren-delay 0)
(show-paren-mode 1)

(set-fringe-mode 8)

(setq frame-title-format
      '((:eval (if (buffer-file-name)
                   (abbreviate-file-name (buffer-file-name))
                 "%b"))
        " — Emacs"))

(provide 'setup-ui)
;;; setup-ui.el ends here
#+end_src

* Editor basics                                                  :EDITOR:
:PROPERTIES:
:CUSTOM_ID: editor
:END:

Defaults that turn Emacs from a 1990s text editor into a comfortable
modern one.

- *Short answers* (~y~/~n~ instead of ~yes~/~no~) via the first-class
  ~use-short-answers~ option (Emacs 28+).

- *UTF-8 everywhere* (charset priority, default coding system,
  terminal and keyboard).

- *Spaces by default*, but ~tab-width~ stays at 4 so tab-indented
  files render correctly.  Per-language major modes that legitimately
  want tabs (Makefile, Go) override the default locally.

- *Backup and auto-save under ~var/~.*  By default Emacs litters the
  whole filesystem with ~foo~~ and ~#foo#~ files; we funnel both into
  ~var/backups/~ and ~var/auto-save/~ so the rest of the disk stays
  clean.  Lock files (~.#foo~) are disabled outright -- they confuse
  external tools (webpack, vim, file watchers) and are useful only in
  multi-user setups.

- *Persistent state.*  Built-in but off by default: ~recentf~ (recent
  files list), ~saveplace~ (point position across sessions),
  ~savehist~ (minibuffer history, search rings, kill ring).

- *Quiet auto-revert*: refresh buffers when the underlying file
  changes, including dired and magit buffers.  Useful when pulling
  git changes from another window.

- *Pairing and selection.*  ~electric-pair-mode~,
  ~delete-selection-mode~ and ~transient-mark-mode~ all on -- the
  expected behaviour in any modern editor.

- *Trailing whitespace.*  Stripped on save, but only in ~prog-mode~
  buffers; in prose (org, markdown) trailing spaces sometimes have
  semantic meaning.

- *Pulse on jump.*  When you switch window or use ~windmove~, the
  destination line briefly pulses so the eye can follow.

- *Auto-tangle of ~config.org~.*  Saving the org file regenerates the
  affected ~setup-*.el~ in place.

#+begin_src emacs-lisp :tangle lisp/setup-editor.el
;;; setup-editor.el --- Core editing behaviour -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Editor basics".

;;; Code:

(setq use-short-answers t)

(set-charset-priority 'unicode)
(prefer-coding-system        'utf-8-unix)
(set-default-coding-systems  'utf-8-unix)
(set-terminal-coding-system  'utf-8-unix)
(set-keyboard-coding-system  'utf-8-unix)
(setq locale-coding-system   'utf-8-unix)

(setq-default indent-tabs-mode nil
              tab-width        4)

(let ((backup-dir   (expand-file-name "var/backups/"   user-emacs-directory))
      (autosave-dir (expand-file-name "var/auto-save/" user-emacs-directory)))
  (make-directory backup-dir   t)
  (make-directory autosave-dir t)
  (setq backup-directory-alist         `(("." . ,backup-dir))
        auto-save-file-name-transforms `((".*" ,autosave-dir t))
        backup-by-copying              t
        version-control                t
        delete-old-versions            t
        kept-new-versions              5
        kept-old-versions              2))

(setq create-lockfiles      nil
      require-final-newline t
      ring-bell-function    'ignore)

(use-package recentf
  :ensure nil
  :init   (setq recentf-max-saved-items 200
                recentf-max-menu-items  25
                recentf-auto-cleanup    'never)
  :config (recentf-mode 1))

(use-package saveplace
  :ensure nil
  :config (save-place-mode 1))

(use-package savehist
  :ensure nil
  :init   (setq savehist-additional-variables
                '(search-ring regexp-search-ring kill-ring))
  :config (savehist-mode 1))

(use-package autorevert
  :ensure nil
  :init (setq auto-revert-verbose                nil
              global-auto-revert-non-file-buffers t)
  :config (global-auto-revert-mode 1))

(electric-pair-mode    1)
(delete-selection-mode 1)
(transient-mark-mode   1)

(defun emacs.d/strip-trailing-whitespace-prog ()
  "Strip trailing whitespace in `prog-mode' buffers only."
  (when (derived-mode-p 'prog-mode)
    (delete-trailing-whitespace)))

(add-hook 'before-save-hook #'emacs.d/strip-trailing-whitespace-prog)

(add-hook 'text-mode-hook #'visual-line-mode)

(when (fboundp 'pulse-momentary-highlight-one-line)
  (defun emacs.d/pulse-line (&rest _) (pulse-momentary-highlight-one-line (point)))
  (dolist (cmd '(other-window
                 windmove-up windmove-down windmove-left windmove-right))
    (advice-add cmd :after #'emacs.d/pulse-line)))

(defun emacs.d/auto-tangle-config ()
  "Tangle `config.org' on save when the current buffer is that file."
  (when (and buffer-file-name
             (string-equal (file-name-nondirectory buffer-file-name)
                           "config.org")
             (file-equal-p (file-name-directory buffer-file-name)
                           user-emacs-directory))
    (let ((org-confirm-babel-evaluate nil))
      (org-babel-tangle))))

(add-hook 'after-save-hook #'emacs.d/auto-tangle-config)

(provide 'setup-editor)
;;; setup-editor.el ends here
#+end_src

* Completion                                                :COMPLETION:
:PROPERTIES:
:CUSTOM_ID: completion
:END:

The "modern" Emacs completion stack -- small, modular, each package
does one thing and they compose freely.

| Layer             | Package                       | Role                                            |
|-------------------+-------------------------------+-------------------------------------------------|
| Minibuffer UI     | [[https://github.com/minad/vertico][vertico]]                       | Vertical candidate list                         |
| Annotations       | [[https://github.com/minad/marginalia][marginalia]]                    | File size, key, docstring next to candidates    |
| Matching style    | [[https://github.com/oantolin/orderless][orderless]]                     | Type space-separated tokens in any order        |
| Search & navigate | [[https://github.com/minad/consult][consult]]                       | Buffer / line / imenu / ripgrep pickers         |
| In-buffer popup   | [[https://github.com/minad/corfu][corfu]]                         | VSCode-style autocomplete inside a buffer       |
| Extra backends    | [[https://github.com/minad/cape][cape]]                          | File paths, dabbrev, keywords for ~corfu~       |
| Key hints         | ~which-key~ (built in 30+)    | Pop-up listing keys after a prefix              |

A note on ~orderless~: the ~completion-styles~ list also keeps the
built-in ~basic~ style as a fallback, which is necessary for
prefix-driven completion (TRAMP file names in particular) to work.

Consult bindings worth remembering:

| Key       | Command                       |
|-----------+-------------------------------|
| ~C-x b~   | ~consult-buffer~              |
| ~M-y~     | ~consult-yank-pop~            |
| ~M-g g~   | ~consult-goto-line~           |
| ~M-g i~   | ~consult-imenu~               |

  :custom

(use-package corfu
  :init (global-corfu-mode 1)

** Auto-starting Eglot
:PROPERTIES:
:CUSTOM_ID: prog-eglot-modes
:END:

The variable ~emacs.d/eglot-auto-modes~ lists the major modes for
which Eglot should auto-attach.  Eglot only actually starts when the
matching language server is found on ~PATH~, so leaving entries here
for languages whose server you have not installed is harmless --
they're inert.

To stop auto-attach for a language, customise that variable; to add
one, append the major mode symbol.

** Installing language servers
:PROPERTIES:
:CUSTOM_ID: prog-lsp-install
:END:

Eglot does *not* install language servers (unlike ~lsp-mode~ with
~lsp-install-server~ or ~mason.nvim~ on the Neovim side).  Three
reasonable strategies, in increasing order of reproducibility:

1. *System-wide* via distro packages (quick, requires sudo, version
   pinned by your distro).
2. *Per-user* (recommended): ~pip install --user~,
   ~rustup component add rust-analyzer~, ~go install ...@latest~,
   ~npm i -g ...~ with a user prefix.  No sudo, easy to upgrade,
   isolated from system Python/Node.
3. *Per-project* via ~nix develop~, ~mise~, ~asdf~, a devcontainer or

* TRAMP                                                          :TRAMP:
:PROPERTIES:
:CUSTOM_ID: tramp
:END:

Open ~/ssh:host:/path~ to edit a remote file as if it were local.

This module trades a bit of TRAMP's default paranoia for a much
faster experience over SSH while keeping the security properties of
plain ~ssh~ -- host-key checking is *never* disabled.

Pre-requisites on the local machine:

- a working ~ssh~ on ~PATH~ (Emacs uses the system OpenSSH);
- an ~~/.ssh/config~ with ~ControlMaster auto~ for the hosts you visit
  often.  With ControlMaster set up every TRAMP operation reuses the
  same SSH connection -- the single biggest speed win for remote
  editing.  Sample block:

  #+begin_example
  Host *
      ControlMaster auto
      ControlPath   ~/.ssh/cm-%r@%h:%p
      ControlPersist 10m
      ServerAliveInterval 60
  #+end_example

Notable knobs we set:

- ~tramp-default-method "ssh"~ -- uses your OpenSSH client and
  benefits from ControlMaster.
- ~tramp-verbose 1~ silences the per-step "Connecting to..."
  progress noise; bump it back to 6 when debugging a connection.
- ~vc-handled-backends '(Git)~ -- TRAMP probes every visited file for
  VCS metadata, slow over SSH.  We restrict it to Git (Magit talks
  through one shared SSH session and is fast on remote repos).
- ~tramp-archive-enabled nil~ -- the archive handler matches archive
  members on remote paths and slows down every find-file.
- ~remote-file-name-inhibit-auto-save-visited t~ -- auto-saving over
  SSH is slow and the local copy defeats the point of editing
  remotely; ~C-x C-s~ still saves explicitly.
- ~recentf~ excludes remote files (they expire / change IPs and probing
  them on startup is slow), and ~saveplace~ skips them too.

;; See config.org, section "TRAMP".

;;; Code:

  "Around-advice that skips `save-place' bookkeeping for remote files."
  (unless (and buffer-file-name (file-remote-p buffer-file-name))
    (apply orig-fn args)))

(use-package tramp
  :ensure nil
  :defer t
  :custom

  :config

* Terminal: vterm + tab-bar                                  :TERMINAL:
:PROPERTIES:
:CUSTOM_ID: terminal
:END:

The "Emacs as a daily SSH terminal" stack: each remote session lives
in its own ~tab-bar~ tab and the tab title is /dynamic/ -- it shows
the bastion / jump host the session was opened against, plus the
hostname extracted from the current shell prompt.

** vterm
:PROPERTIES:
:CUSTOM_ID: terminal-vterm
:END:

[[https://github.com/akermu/emacs-libvterm][vterm]] is an NCURSES-compatible terminal that runs full TUIs (htop,
vi, less, tmux, interactive password prompts) without surprises.  We
prefer it over the built-in ~term~/~ansi-term~/~eshell~ for these
workloads because it's the only one that handles complex remote
sessions transparently.

First boot compiles a small C module against ~libvterm~.  The
package tries the system ~libvterm~ first; if ~libvterm-dev~ (Debian)
/ ~libvterm-devel~ (RHEL) headers are missing it falls back to
downloading and building libvterm via cmake's FetchContent.  Either
way ~cmake~, ~gcc~ and ~libtool~ are needed.

Bindings:

| Key         | Where               | Action                          |
|-------------+---------------------+---------------------------------|
| ~C-c v~     | global              | open a *local* vterm            |
| ~C-c C-t~   | inside vterm        | toggle ~vterm-copy-mode~        |
| ~C-c s s~   | global              | open a saved SSH session in a tab (see [[#ssh-sessions][SSH sessions]]) |

A few non-default options:

- ~vterm-max-scrollback 10000~ keeps a useful amount of scrollback
  without blowing memory on long-running sessions.
- ~vterm-kill-buffer-on-exit nil~ keeps the buffer around after the
  process exits so the last lines of output (e.g. SSH error
  messages) remain readable.

** Tab bar
:PROPERTIES:
:CUSTOM_ID: terminal-tab-bar
:END:

~tab-bar-mode~ is built in.  It is enabled globally; the bar
auto-hides when only one tab is open, so it adds no visual noise
during normal editing.  New tabs land on ~*scratch*~.

| Key             | Action                       |
|-----------------+------------------------------|
| ~C-x t t~       | new tab                      |
| ~C-x t k~       | close current tab            |
| ~C-x t l~       | switch to next tab           |
| ~C-x t h~       | switch to previous tab       |
| ~C-x t r~       | rename current tab           |
| ~C-<tab>~       | next tab (built-in default)  |
| ~C-S-<tab>~     | previous tab (built-in default) |

** Dynamic tab title
:PROPERTIES:
:CUSTOM_ID: terminal-dynamic-title
:END:

Three buffer-local variables drive the title machinery:

- ~emacs.d/vterm-bastion-name~ -- string set once when the session is
  opened (by [[#ssh-sessions][setup-ssh-sessions]]).  Static for the lifetime of the
  session.  Used as the prefix of the tab title.
- ~emacs.d/vterm-current-host~ -- updated by parsing the latest
  visible shell prompt against ~emacs.d/vterm-prompt-host-regexp~.
  May be nil while the prompt is still being drawn.
- ~emacs.d/vterm-tab-name~ -- the tab title last installed.  Stored
  so the right tab can be located by name when the host changes,
  even if the user has switched to a different tab in the meantime.

The default regexp matches the typical Linux PS1 forms:

#+begin_example
[user@host pwd]$
 user@host:pwd$
 user@host pwd>
#+end_example

No remote ~.bashrc~ modification is required -- we read what is
already on screen.

The strategy is to /not/ intercept ~tab-bar-tab-name-function~ (which
is invoked for every tab on every redraw and forces a 0-arg
signature), and instead explicitly call ~tab-bar-rename-tab~
whenever the session detects a new host.  The relevant tab is
located by name through the helper ~emacs.d/tab-bar-rename-tab-by-name~,
so the rename works regardless of which tab is currently selected.

** Closing sessions
:PROPERTIES:
:CUSTOM_ID: terminal-closing
:END:

Two related conveniences for the SSH workflow:

- *Dismissing a dead session.*  When the remote shell exits (you
  typed ~exit~, SSH dropped, CyberArk PSMP timed you out), the buffer
  is intentionally left around so the last lines of output remain
  readable.  ~vterm-exit-functions~ installs a minimal local keymap
  inheriting from the existing one, with a single addition: ~q~
  bound to ~kill-current-buffer~.  A ~[exited]~ marker is added to
  the mode line so the dead state is visible at a glance.

- *Auto-closing the tab.*  When a session vterm buffer is killed
  (via ~q~ or ~kill-buffer~), the tab that hosted it is closed too
  -- otherwise the user ends up with orphan tabs each pointing at
  ~*scratch*~.  This is opt-in: only vterms opened by [[#ssh-sessions][setup-ssh-sessions]]
  install the ~kill-buffer-hook~; vterms launched casually with
  ~C-c v~ keep the default Emacs "leave the tab open" behaviour.
  The very last tab on the frame is preserved (closing it would
  signal an error and the user almost certainly wants to keep the
  frame).

#+begin_src emacs-lisp :tangle lisp/setup-terminal.el
;;; setup-terminal.el --- vterm + tab-bar -*- lexical-binding: t; -*-

;;; Commentary:
;; See config.org, section "Terminal: vterm + tab-bar".

;;; Code:

(require 'cl-lib)

(use-package vterm
  :commands (vterm vterm-other-window)
  :custom
  (vterm-max-scrollback     10000)
  (vterm-kill-buffer-on-exit nil)
  (vterm-buffer-name-string "vterm: %s")
  (vterm-shell (or explicit-shell-file-name (getenv "SHELL") "/bin/bash"))
  :bind
  (("C-c v" . vterm)
   :map vterm-mode-map
        ("C-c C-t" . vterm-copy-mode)))

(use-package tab-bar
  :ensure nil
  :init (setq tab-bar-show               1
              tab-bar-new-tab-choice     "*scratch*"
              tab-bar-close-button-show  nil
              tab-bar-new-button-show    nil)
  :bind
  (("C-x t t" . tab-bar-new-tab)
   ("C-x t k" . tab-bar-close-tab)
   ("C-x t l" . tab-bar-switch-to-next-tab)
   ("C-x t h" . tab-bar-switch-to-prev-tab)
   ("C-x t r" . tab-bar-rename-tab))
  :config (tab-bar-mode 1))

(defvar-local emacs.d/vterm-bastion-name nil
  "Bastion / jump host this vterm session was opened against.
Set by `setup-ssh-sessions' at session creation; static thereafter.")

(defvar-local emacs.d/vterm-current-host nil
  "Hostname extracted from the most recent visible shell prompt.")

(defvar-local emacs.d/vterm-tab-name nil
  "Last tab title applied for this vterm buffer.
Used to find the right tab to rename when the prompt host changes.")

(defcustom emacs.d/vterm-prompt-host-regexp
  "[][:alnum:]_.-]*@\\([[:alnum:]_.-]+\\)[ :]"
  "Regexp used to extract the current hostname from a shell prompt.
Capture group 1 must be the hostname."
  :type 'regexp :group 'emacs.d)

(defun emacs.d/vterm-extract-prompt-host ()
  "Return the hostname captured by the most recent prompt-like match."
  (save-excursion
    (goto-char (point-max))
    (let ((window-start (max (point-min)
                             (save-excursion (forward-line -50) (point)))))
      (when (re-search-backward emacs.d/vterm-prompt-host-regexp
                                window-start t)
        (match-string-no-properties 1)))))

(defun emacs.d/tab-bar-rename-tab-by-name (old-name new-name)
  "Rename the tab named OLD-NAME to NEW-NAME on the selected frame.
Returns non-nil on success, nil if no tab has OLD-NAME."
  (let* ((tabs (funcall tab-bar-tabs-function))
         (idx  (cl-position old-name tabs
                            :key  (lambda (tab) (alist-get 'name tab))
                            :test #'string-equal)))
    (when idx
      ;; tab-bar-rename-tab is 1-based; passing the index is required so
      ;; we do not accidentally rename whichever tab is currently selected.
      (tab-bar-rename-tab new-name (1+ idx))
      t)))

(defun emacs.d/vterm-update-current-host (&rest _ignored)
  "Refresh the host derived from the prompt and rename the tab if needed.
Hooked as `:after' advice on `vterm--filter'."
  (when (derived-mode-p 'vterm-mode)
    (let ((new-host (emacs.d/vterm-extract-prompt-host)))
      (when (and new-host
                 (not (equal new-host emacs.d/vterm-current-host)))
        (setq-local emacs.d/vterm-current-host new-host)
        (let* ((bastion      emacs.d/vterm-bastion-name)
               (new-tab-name (if bastion
                                 (format "%s: %s" bastion new-host)
                               new-host)))
          (when (and (bound-and-true-p tab-bar-mode)
                     emacs.d/vterm-tab-name
                     (not (string-equal new-tab-name
                                        emacs.d/vterm-tab-name)))
            (when (emacs.d/tab-bar-rename-tab-by-name
                   emacs.d/vterm-tab-name new-tab-name)
              (setq-local emacs.d/vterm-tab-name new-tab-name))))))))

(with-eval-after-load 'vterm
  (advice-add 'vterm--filter :after #'emacs.d/vterm-update-current-host))

(defun emacs.d/vterm-handle-exit (buf _event)
  "Make `q' kill BUF and mark its mode line `[exited]' once vterm dies."
  (when (buffer-live-p buf)
    (with-current-buffer buf
      (let ((map (make-sparse-keymap)))
        (set-keymap-parent map (current-local-map))
        (define-key map (kbd "q") #'kill-current-buffer)
        (use-local-map map))
      (setq-local mode-line-process
                  (propertize " [exited]" 'face 'shadow))
      (force-mode-line-update))))

(with-eval-after-load 'vterm
  (add-hook 'vterm-exit-functions #'emacs.d/vterm-handle-exit))

(defun emacs.d/vterm-close-tab-on-kill ()
  "Close the tab hosting this buffer when it is killed.
Installed buffer-locally by `setup-ssh-sessions' on session vterms.
Refuses to close the last surviving tab."
  (when (and (bound-and-true-p tab-bar-mode)
             emacs.d/vterm-tab-name)
    (let* ((tabs (funcall tab-bar-tabs-function))
           (idx  (cl-position emacs.d/vterm-tab-name tabs
                              :key  (lambda (tab) (alist-get 'name tab))
                              :test #'string-equal)))
      (when (and idx (> (length tabs) 1))
        ;; Defer the close: doing it from inside `kill-buffer-hook'
        ;; can leave the buffer-list traversal in an inconsistent state.
        (run-at-time 0 nil #'tab-bar-close-tab (1+ idx))))))

(provide 'setup-terminal)

* SSH sessions                                                :SESSIONS:
:PROPERTIES:
:CUSTOM_ID: ssh-sessions
:END:

A small "session manager" inspired by the saved sessions of
MobaXterm, Termius or PuTTY -- built natively on top of [[#terminal][vterm + tab-bar]].

The connection method is plain ~ssh~ inside vterm, *not* TRAMP.  The
real-life flow involves CyberArk PSMP and other interactive prompts
(MFA, password change, banner acknowledgements) that don't fit
TRAMP's model; we want the saving in not having to remember the
host, user and port -- not in trying to script the credentials.

** Storage and schema
:PROPERTIES:
:CUSTOM_ID: ssh-sessions-schema
:END:

Sessions live in =var/ssh-sessions.el= (gitignored).  Each entry is
a plist; the file contains a single Lisp form -- a list of plists.

Recognised fields:

| Field          | Required | Meaning                                                       |
|----------------+----------+---------------------------------------------------------------|
| ~:name~        | yes      | Unique label.  Becomes the initial tab title.                 |
| ~:host~        | yes      | Remote hostname or IP.                                        |
| ~:user~        | no       | Remote username.  Defaults to the local user.                 |
| ~:port~        | no       | TCP port.  Default 22.                                        |
| ~:command~     | no       | Full command override; if present, ~:host~/~:user~/~:port~ are ignored. Useful for ProxyJump chains, Kerberized wrappers, custom CyberArk launchers. |
| ~:group~       | no       | Free-form classification for completing-read annotations.     |
| ~:description~ | no       | Free-form note.                                               |

Example:

#+begin_src emacs-lisp :tangle no
(:name        "prod-bastion-1"
 :host        "bastion1.acme.com"
 :user        "myuser"
 :port        22
 :group       "Production"
 :description "CyberArk PSMP entry to prod tier")
#+end_src

** Bindings
:PROPERTIES:
:CUSTOM_ID: ssh-sessions-keys
:END:

| Key       | Command                          | Purpose                                                 |
|-----------+----------------------------------+---------------------------------------------------------|
| ~C-c s s~ | ~emacs.d/ssh-sessions-open~      | Pick a session and open it in a new tab                 |
| ~C-c s a~ | ~emacs.d/ssh-sessions-add~       | Define a new session interactively                      |
| ~C-c s e~ | ~emacs.d/ssh-sessions-edit~      | Open the storage file for direct editing                |

The completing-read prompt offers Vertico annotations showing host,
group and description -- so all three are searchable with Orderless
tokens.

** Lifecycle
:PROPERTIES:
:CUSTOM_ID: ssh-sessions-lifecycle
:END:

Opening a session:

1. Creates a new tab and renames it to the session ~:name~ /
   immediately/, so the bastion label is visible before SSH has even
   authenticated.
2. Spawns a vterm whose shell is the synthesised ~ssh~ command (or
   the explicit ~:command~ override).
3. Marks the buffer with ~emacs.d/vterm-bastion-name~ and

* SSH tunnels                                                  :TUNNELS:
:PROPERTIES:
:CUSTOM_ID: ssh-tunnels
:END:

A small manager for SSH port-forwarding tunnels.  Mental model:
"MobaXterm's tunnel list" living in an Emacs buffer with explicit
on/off toggles.

Tunnels run as native Emacs subprocesses (no shell wrapper), so they
die cleanly when Emacs exits and their stderr is captured in
=*ssh-tunnel: NAME*= buffers if anything goes wrong.  Each ssh
invocation is run with ~-N -T~ (no remote shell, no PTY) plus
~ServerAliveInterval=30~, ~ServerAliveCountMax=3~ and
~ExitOnForwardFailure=yes~ -- helpful behind CyberArk PSMP and other
corporate firewalls that idle-kill connections silently.

** Storage and schema
:PROPERTIES:
:CUSTOM_ID: ssh-tunnels-schema
:END:

Tunnels live in =var/ssh-tunnels.el= (gitignored).  Each entry is a
plist; the file contains a single Lisp form -- a list of plists.

| Field          | Required          | Meaning                                                |
|----------------+-------------------+--------------------------------------------------------|
| ~:name~        | yes               | Unique label.                                          |
| ~:type~        | yes               | One of ~local~, ~remote~, ~dynamic~.                   |
| ~:local-port~  | yes               | Local TCP port (or, for ~dynamic~, the SOCKS port).    |
| ~:remote-host~ | local / remote    | Hostname /as seen from the bastion/.  Ignored for ~dynamic~. |
| ~:remote-port~ | local / remote    | TCP port on the remote host.  Ignored for ~dynamic~.   |
| ~:via-host~    | yes               | The SSH host through which the tunnel is opened.       |
| ~:via-user~    | no                | Username for the SSH connection.                       |
| ~:description~ | no                | Free-form note.                                        |

Type semantics (mirrors the OpenSSH manual):

- ~local~  → ~ssh -L LP:RH:RP user@VIA~  (forward a local port to a remote address through the bastion)
- ~remote~ → ~ssh -R LP:RH:RP user@VIA~  (forward a remote port back to a local address)
- ~dynamic~ → ~ssh -D LP user@VIA~  (turn the bastion into a SOCKS proxy on local port LP)

Example:

#+begin_src emacs-lisp :tangle no
(:name        "weblogic-prod-console"
 :type        local
 :local-port  7001
 :remote-host "weblogic.internal.acme"
 :remote-port 7001
 :via-host    "bastion.acme.com"
 :via-user    "myuser"
 :description "Open http://localhost:7001/console")
#+end_src

** Bindings
:PROPERTIES:
:CUSTOM_ID: ssh-tunnels-keys
:END:

Global:

| Key       | Command                       | Purpose                          |
|-----------+-------------------------------+----------------------------------|
| ~C-c s t~ | ~emacs.d/ssh-tunnels-show~    | Open the tunnels list buffer     |
| ~C-c s T~ | ~emacs.d/ssh-tunnels-add~     | Define a new tunnel              |

Inside the list buffer:

| Key   | Action                              |
|-------+-------------------------------------|
| ~RET~ | toggle tunnel on point on/off       |
| ~t~   | same as RET                         |
| ~a~   | add a tunnel                        |
| ~d~   | delete tunnel on point              |
| ~e~   | edit the tunnels file directly      |
| ~K~   | stop ALL active tunnels             |
| ~g~   | refresh the list                    |

Active tunnels are marked with a green ● in the leftmost column;
inactive ones with a grey ○.

  (let ((proc (gethash name emacs.d/ssh-tunnels--processes)))

(defun emacs.d/ssh-tunnels--build-args (tunnel)
  "Return the argv (no program) to launch TUNNEL via ssh."
  (let* ((type   (plist-get tunnel :type))
         (lport  (plist-get tunnel :local-port))
         (rhost  (plist-get tunnel :remote-host))
         (rport  (plist-get tunnel :remote-port))
         (via    (plist-get tunnel :via-host))
         (user   (plist-get tunnel :via-user))
         (target (if user (format "%s@%s" user via) via)))
    (append
     '("-N" "-T")
     ;; Keepalive + fail-fast: helpful behind CyberArk PSMP and other
     ;; corporate firewalls that idle-kill connections silently.
     '("-o" "ServerAliveInterval=30"
       "-o" "ServerAliveCountMax=3"
       "-o" "ExitOnForwardFailure=yes")
     (cl-case type
       (local   (list "-L" (format "%d:%s:%d" lport rhost rport)))
       (remote  (list "-R" (format "%d:%s:%d" lport rhost rport)))
       (dynamic (list "-D" (format "%d" lport)))
       (t       (error "Unknown tunnel type: %S" type)))
     (list target))))

(defun emacs.d/ssh-tunnels--start (tunnel)
  "Spawn the ssh subprocess for TUNNEL and register its sentinel."
  (let* ((name (plist-get tunnel :name))
         (args (emacs.d/ssh-tunnels--build-args tunnel))
         (buf  (get-buffer-create (format "*ssh-tunnel: %s*" name)))
         (proc (apply #'start-process
                      (format "ssh-tunnel-%s" name)
                      buf
                      "ssh" args)))
    (puthash name proc emacs.d/ssh-tunnels--processes)
    (set-process-sentinel
     proc
     (lambda (p _event)
       (unless (process-live-p p)
         (remhash name emacs.d/ssh-tunnels--processes)
         (when (get-buffer "*ssh-tunnels*")
           (with-current-buffer "*ssh-tunnels*" (revert-buffer))))))
    (message "Tunnel %S started (pid %d)" name (process-id proc))))

(defun emacs.d/ssh-tunnels--stop (name)
  "Signal the live ssh process for tunnel NAME to terminate cleanly."
  (when-let ((proc (gethash name emacs.d/ssh-tunnels--processes)))
    (when (process-live-p proc)
      (interrupt-process proc)
      (run-at-time 0.5 nil
                   (lambda ()
                     (when (process-live-p proc)
                       (kill-process proc))))
      (message "Tunnel %S stopped" name))))

(defun emacs.d/ssh-tunnels--format-spec (tunnel)
  "Render a one-line forwarding spec for TUNNEL."
  (let ((type  (plist-get tunnel :type))
        (lport (plist-get tunnel :local-port))
        (rhost (plist-get tunnel :remote-host))
        (rport (plist-get tunnel :remote-port)))
    (cl-case type
      (local   (format "L %s -> %s:%s" lport rhost rport))
      (remote  (format "R %s -> %s:%s" lport rhost rport))
      (dynamic (format "D %s (SOCKS)"  lport))

(defun emacs.d/ssh-tunnels--refresh-entries ()
  (emacs.d/ssh-tunnels--ensure-loaded)
  (setq tabulated-list-entries
        (mapcar
         (lambda (tunnel)
           (let* ((name    (plist-get tunnel :name))
                  (type    (plist-get tunnel :type))
                  (via     (plist-get tunnel :via-host))
                  (user    (plist-get tunnel :via-user))
                  (descr   (or (plist-get tunnel :description) ""))
                  (running (emacs.d/ssh-tunnels--running-p name))
                  (dot     (if running
                               (propertize "●" 'face 'success)
                             (propertize "○" 'face 'shadow))))
             (list name
                   (vector dot
                           name
                           (symbol-name type)
                           (emacs.d/ssh-tunnels--format-spec tunnel)
                           (if user (format "%s@%s" user via) (or via ""))
                           descr))))
         emacs.d/ssh-tunnels)))

    (message "Tunnels reloaded (%d entries)."
             (length emacs.d/ssh-tunnels))))
